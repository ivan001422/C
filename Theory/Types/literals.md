# Литералы в C

**Литералы (константы)** — это фиксированные значения, которые записываются непосредственно в коде и не могут быть изменены программой.  
Каждый литерал имеет определённый тип, зависящий от его записи и суффиксов.

## Символьные литералы

Заключаются в одинарные кавычки. В C есть несколько префиксов (C11 и новее):

| Запись | Тип | Описание |
|---|---|---|
| `'A'` | `int` | обычный символ (в C это `int`, а не `char`!) |
| `u'A'` | `char16_t` | UTF-16 (C11) |
| `U'A'` | `char32_t` | UTF-32 (C11) |
| `L'A'` | `wchar_t` | широкий символ |

Важно: в C `sizeof('A') == sizeof(int)`, а не `1`. Это историческая особенность, унаследованная от ранних версий языка. В выражениях символьный литерал ведёт себя как `int`.

Символьный литерал может содержать:
- один обычный символ: `'A'`, `'z'`, `'0'`;
- управляющую последовательность: `'\n'`, `'\t'`, `'\0'`;
- escape-код: `'\x41'`, `'\101'`;
- multi-character literal: `'AB'` — implementation-defined, обычно `(A<<8)|B`. Использовать не рекомендуется.

## Целочисленные литералы

Записываются как числа без дробной части.  
Суффиксы уточняют тип (регистр не важен, но `L` лучше писать заглавной, чтобы не путать с `1`):

| Литерал | Тип |
|---|---|
| `123` | `int` (по умолчанию) |
| `123u` / `123U` | `unsigned int` |
| `123l` / `123L` | `long` |
| `123ll` / `123LL` | `long long` (C99) |
| `123ul` | `unsigned long` |
| `123ull` | `unsigned long long` (C99) |

## Литералы с плавающей точкой

Содержат десятичную точку или экспоненту.  
По умолчанию имеют тип **`double`**.  
Суффиксы меняют точность:

| Литерал | Тип |
|---|---|
| `3.14` | `double` |
| `3.14f` / `3.14F` | `float` |
| `3.14l` / `3.14L` | `long double` |

В C99 добавились **шестнадцатеричные литералы с плавающей точкой**:

```c
double x = 0x1.8p3;    // 1.5 * 2^3 = 12.0
double y = 0x1p-2;     // 0.25
```

Формат: `0x` + мантисса + `p` + степень двойки (обязательно десятичная).

## Правила определения типа компилятором

- **Целые числа**: выбирается первый подходящий тип из списка:  
  `int` → `long` → `long long` (для десятичных);  
  `int` → `unsigned int` → `long` → `unsigned long` → `long long` → `unsigned long long` (для hex/octal).
- **Плавающая точка**: по умолчанию используется `double`.

Явные суффиксы переопределяют эти правила и гарантируют нужный тип.

## Шестнадцатеричные, восьмеричные и двоичные литералы

- **Десятичные**: обычная запись. `42`, `1000`.
- **Восьмеричные**: префикс `0` (ноль). `011` = 9, `052` = 42. **Легко перепутать с десятичными!**
- **Шестнадцатеричные**: префикс `0x` или `0X`. `0xFF` = 255, `0x2A` = 42.
- **Двоичные** (C23): префикс `0b` или `0B`. `0b101010` = 42. До C23 — расширение компилятора.

```c
int dec = 42;      // 42
int oct = 042;     // 34
int hex = 0x2A;    // 42
int bin = 0b101010; // 42 (C23)
```

## Строковые литералы

Заключаются в двойные кавычки. Имеют тип `char[N]`, где `N` включает завершающий `'\0'`.

```c
"hello"    // char[6]: 'h','e','l','l','o','\0'
""         // char[1]: только '\0'
```

Строковые литералы — **read-only**. Попытка изменить их — неопределённое поведение.

```c
char arr[] = "hello";       // копия в изменяемую память
const char *p = "hello";    // указатель на read-only
// p[0] = 'H';              // UB
```

### Конкатенация

Соседние строковые литералы склеиваются на этапе компиляции:

```c
"hello" " " "world"    // то же, что "hello world"
```

### Префиксы (C11)

| Запись | Тип | Описание |
|---|---|---|
| `"..."` | `char[]` | обычная строка |
| `u8"..."` | `char[]` | UTF-8 (C11; в C23 — `char8_t[]`) |
| `u"..."` | `char16_t[]` | UTF-16 |
| `U"..."` | `char32_t[]` | UTF-32 |
| `L"..."` | `wchar_t[]` | широкая строка |

## Управляющие последовательности

Вставляются в символьные и строковые литералы для представления специальных символов.  
Начинаются с обратного слеша `\`.

| Код | Значение |
|---|---|
| `\b` | Возврат на одну позицию (Backspace) |
| `\f` | Подача страницы (Form feed) |
| `\n` | Новая строка (New line) |
| `\r` | Возврат каретки (Carriage return) |
| `\t` | Горизонтальный отступ (Tab) |
| `\v` | Вертикальный отступ (Vertical tab) |
| `\a` | Звуковой сигнал (Alert/Bell) |
| `\0` | Нулевой символ (null terminator) |
| `\"` | Двойная кавычка |
| `\'` | Одинарная кавычка (апостроф) |
| `\\` | Обратный слэш |
| `\?` | Вопросительный знак |
| `\N` | Восьмеричный код (`N` — цифры 0–7), до 3 цифр |
| `\xN` | Шестнадцатеричный код (`N` — hex-цифры), любое число цифр |
| `\uNNNN` | Универсальное имя символа (C99, 4 hex-цифры) |
| `\UNNNNNNNN` | Универсальное имя символа (C99, 8 hex-цифр) |

Осторожно с `\x`: escape съедает **все** последующие hex-цифры.  
`"\x41B"` — это не `"AB"`, а символ с кодом `0x41B` (если влезет в `char` — UB/усечение).  
Правильно: `"\x41" "B"` или `"\101B"`.

## Логические литералы

В C99 через `<stdbool.h>`:

```c
#include <stdbool.h>

bool a = true;   // 1
bool b = false;  // 0
```

В C23 `true`, `false`, `bool` — ключевые слова, `<stdbool.h>` не нужен.

## `NULL`

Макрос из `<stddef.h>` (и других заголовков). Обычно `((void*)0)` или `0`.

```c
int *p = NULL;
char c = '\0';   // не NULL — это разные вещи
int x = 0;       // не NULL — для чисел
```

Правила:
- для указателей — `NULL`;
- для символов — `'\0'`;
- для чисел — `0`.

## Составные литералы (C99)

Compound literals позволяют создавать объект структуры или массива прямо в выражении:

```c
(struct Point){ .x = 1, .y = 2 }
(int[]){ 1, 2, 3 }
```

Время жизни:
- внутри функции — до конца блока;
- в файловой области — вся программа.

## Пример использования

```c
#include <stdio.h>

int main(void) {
    printf("Привет,\nмир!\n");                 // Перевод строки
    printf("Табуляция:\tтекст\n");             // Горизонтальный отступ
    printf("Кавычки: \"C\"\n");                // Двойные кавычки
    printf("Звук:\a\n");                       // Звуковой сигнал
    printf("Обратный слэш: \\n\n");            // Вывод \n как текста
    printf("Восьмеричный код A: \101\n");      // 'A' (ASCII 65 восьм.)
    printf("Шестнадцатеричный код A: \x41\n"); // 'A' (ASCII 65 hex)

    printf("dec=%d oct=%d hex=%d\n", 42, 042, 0x2A); // 42 34 42
    printf("%zu\n", sizeof('A'));               // sizeof(int), обычно 4
    printf("%zu\n", sizeof("hello"));           // 6

    return 0;
}
```

Примечание: управляющая последовательность интерпретируется компилятором как единый символ, а не как несколько обычных знаков.

## Опасные места

1. **Восьмеричные литералы.** `052` — это 42, а не 52. Ведущий ноль = восьмеричная запись.
2. **`\x` съедает все hex-цифры.** `"\x41B"` — не то, что кажется.
3. **`sizeof('A')` в C — размер `int`**, а не `char`.
4. **Строковые литералы read-only.** Изменение — UB.
5. **`1 / 2` — целочисленное деление**, результат `0`, а не `0.5`.
6. **`3.14` — это `double`**, а не `float`. Для `float` нужен суффикс `f`.
7. **`printf("%d", 3.14)`** — UB: несовпадение формата и типа.
8. **`0x1.8p3` без `p`** — не hex float, а ошибка.
9. **Суффиксы регистрозависимы по смыслу** (`l` vs `L`), но не по действию.

## Шпаргалка

```c
// Целые
42        // int
42u       // unsigned int
42L       // long
42LL      // long long
42UL      // unsigned long
42ULL     // unsigned long long

// Системы счисления
42        // десятичное
052       // восьмеричное (= 42)
0x2A      // шестнадцатеричное (= 42)
0b101010  // двоичное (C23)

// Плавающие
3.14      // double
3.14f     // float
3.14L     // long double
1e10      // double (1 * 10^10)
0x1.8p3   // hex float (= 12.0)

// Символы
'A'       // int в C
'\n' '\t' '\0' '\\' '\'' '\"'
'\x41'    // hex escape
'\101'    // octal escape
'\u00e9'  // universal character name
L'A'      // wchar_t
u'A'      // char16_t (C11)
U'A'      // char32_t (C11)

// Строки
"hello"           // char[6]
"a" "b" "c"       // "abc" — конкатенация
L"wide"           // wchar_t[]
u"utf-16"         // char16_t[] (C11)
U"utf-32"         // char32_t[] (C11)
u8"utf-8"         // UTF-8 (C11)

// Логические (C99, <stdbool.h>)
true, false

// NULL
NULL      // для указателей
'\0'      // для символов
0         // для чисел

// Составные литералы (C99)
(struct Point){ .x = 1, .y = 2 }
(int[]){ 1, 2, 3 }
```
