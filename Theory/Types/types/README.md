# 📘 Типы данных в C

## 1. Целочисленные типы

### Базовые типы

| Тип | Мин. размер (стандарт) | Типичный размер | Типичный диапазон |
|---|---|---|---|
| `char` | 1 байт | 1 байт | −128..127 или 0..255 |
| `short` | 2 байта | 2 байта | −32768..32767 |
| `int` | 2 байта | 4 байта | −2³¹..2³¹−1 |
| `long` | 4 байта | 8 байт (Linux), 4 (Windows) | зависит от платформы |
| `long long` | 8 байт | 8 байт | −2⁶³..2⁶³−1 |

Модификаторы: `signed`, `unsigned`. По умолчанию все целые — `signed`.

### Типы фиксированной ширины (C99, `<stdint.h>`)

```c
int8_t,  int16_t,  int32_t,  int64_t
uint8_t, uint16_t, uint32_t, uint64_t
intptr_t, uintptr_t      // вмещают указатель
intmax_t, uintmax_t      // самые широкие
```

Используй их, когда важен точный размер: бинарные форматы, сетевые протоколы, работа с железом.

### Ключевые правила

- **`sizeof` возвращает `size_t`** — беззнаковый тип. Осторожно при сравнениях с `int`.
- **Знаковое переполнение — UB.** `int x = INT_MAX; x++;` — неопределённое поведение. Беззнаковое переполнение — циклическое и определено стандартом.
- **Целочисленные повышения.** `char` и `short` в арифметике повышаются до `int`.
- **Обычные арифметические преобразования.** При смешивании `int` и `unsigned` результат — `unsigned`.

```c
unsigned u = 10;
int i = -1;
if (i < u) // всегда false: i преобразуется в большое unsigned
    puts("никогда");
```

### Пределы (`<limits.h>`)

```c
INT_MAX, INT_MIN, UINT_MAX
LONG_MAX, LONG_MIN
CHAR_BIT     // число бит в байте (обычно 8)
```

### Форматный вывод (`<inttypes.h>`)

```c
int64_t x = 42;
printf("%" PRId64 "\n", x);
uint32_t y = 7;
printf("%" PRIu32 "\n", y);
```

## 2. Числа с плавающей точкой

### `float` — одинарная точность

- Размер: обычно 4 байта (IEEE 754 binary32).
- Точность: ~7 значащих десятичных цифр.
- Диапазон: ~1.2e−38 .. 3.4e+38.
- Суффикс литерала: `3.14f`.

### `double` — двойная точность

- Размер: обычно 8 байт (IEEE 754 binary64).
- Точность: ~15–16 значащих цифр.
- Диапазон: ~2.2e−308 .. 1.8e+308.
- Литерал без суффикса: `3.14`.

### `long double`

- Размер: зависит от платформы (8, 12, 16 байт).
- Точность: не меньше `double`.
- Суффикс: `3.14L`.

### Особенности

- **Не все числа представимы точно.** `0.1 + 0.2 != 0.3`. Сравнивать на равенство нельзя.
- **`NaN`** — результат 0/0, ∞−∞. Любое сравнение с `NaN` даёт `false`, включая `NaN == NaN`.
- **`Inf`** — переполнение или деление на 0.
- **Деление на 0:** для целых — UB, для `double` — `±Inf` по IEEE 754.

```c
#include <math.h>

isnan(x), isinf(x), isfinite(x), signbit(x)
fabs(x), sqrt(x), pow(x, y), fmod(x, y)
```

### Сравнение

```c
int almost_equal(double a, double b, double eps) {
    return fabs(a - b) < eps;
}
```

Для денег и точных вычислений используй целые (копейки) или рациональную арифметику.

### Пределы (`<float.h>`)

```c
FLT_MAX, FLT_MIN, FLT_EPSILON
DBL_MAX, DBL_MIN, DBL_EPSILON
LDBL_MAX, LDBL_MIN
```

## 3. `char`

- Размер: ровно 1 байт (`CHAR_BIT` бит, обычно 8).
- Может быть `signed` или `unsigned` — **зависит от платформы**.
- Хранит: символы ASCII, байты, маленькие числа.

```c
char c = 'A';        // код 65
char n = 65;         // то же самое
char m = 'A' + 1;    // 'B'
```

### Строки в C

- Строка — это `char[]`, заканчивающийся `'\0'`.
- Литерал `"hello"` имеет тип `char[6]` (5 символов + `'\0'`).
- Литералы — **read-only**. Изменять их — UB.

```c
char arr[] = "hello";       // копия, можно менять
const char *p = "hello";    // указатель на read-only
```

### Опасности

- `char` может быть знаковым: символы > 127 становятся отрицательными.
- Для работы с байтами используй `unsigned char`.
- Функции `toupper`, `isalpha` и т.п. требуют `int`, приведённого к `unsigned char`:

```c
char c = 'a';
toupper(c);                  // потенциально UB
toupper((unsigned char)c);   // правильно
```

### Полезные функции (`<ctype.h>`, `<string.h>`)

```c
isalpha, isdigit, isalnum, isspace, isupper, islower
strlen, strcpy, strncpy, strcmp, strchr, strstr
```

## 4. `enum`

Перечисление — именованные целочисленные константы.

```c
enum Color  { RED, GREEN, BLUE };          // 0, 1, 2
enum Status { OK = 0, WARN = 10, ERR = 20 };
enum Flags  { A = 1, B = 2, C = 4, D = 8 }; // битовые флаги
```

### Особенности

- Значения по умолчанию начинаются с 0 и растут на 1.
- Можно задавать явные значения, в том числе отрицательные.
- Значения могут дублироваться.
- В C `enum` — **не отдельный тип**, а целое. Любое целое присваивается переменной enum без предупреждения.

```c
enum Color c = 42; // компилируется, но семантически неверно
```

### Идиомы

```c
enum Color { RED, GREEN, BLUE, COLOR_COUNT };
const char *color_names[COLOR_COUNT] = { "red", "green", "blue" };
```

Битовые флаги:

```c
enum Perm {
    PERM_READ  = 1 << 0,
    PERM_WRITE = 1 << 1,
    PERM_EXEC  = 1 << 2
};
int p = PERM_READ | PERM_WRITE;
if (p & PERM_READ) { /* ... */ }
```

## 5. Массивы

### Основы

```c
int a[10];              // 10 int, не инициализированы
int b[5] = {1, 2, 3};   // {1, 2, 3, 0, 0}
int c[] = {1, 2, 3, 4}; // размер выведен: 4
int d[5] = {0};         // все нули
```

### Массивы и указатели

Массив **не равен** указателю, но в большинстве выражений **распадается** в указатель на первый элемент.

```c
int a[10];
int *p = a;          // p указывает на a[0]
p[3] == a[3];        // true
*(a + 3) == a[3];    // true
```

Но:

```c
sizeof(a) == 10 * sizeof(int); // размер массива
sizeof(p) == sizeof(int *);    // размер указателя
```

В параметрах функции массив **превращается в указатель**:

```c
void f(int a[10]);   // то же, что int *a
void f(int a[]);     // то же
void f(int *a);      // то же
```

Размер нужно передавать отдельно:

```c
void print(int *a, size_t n);
```

Макрос для размера массива:

```c
#define ARRAY_SIZE(a) (sizeof(a) / sizeof((a)[0]))
```

Работает только для настоящих массивов, не для указателей.

### Многомерные массивы

```c
int m[3][4];                    // 3 строки по 4 int
int m[2][3] = {{1,2,3}, {4,5,6}};
int m[][3] = {{1,2,3}, {4,5,6}}; // первая размерность выводится
```

В памяти — непрерывный блок, row-major:

```c
m[i][j] == *(*(m + i) + j)
```

В параметре вторая размерность обязательна:

```c
void f(int m[][4], size_t rows);
void f(int (*m)[4], size_t rows); // то же
```

### VLA (C99)

```c
void f(size_t n) {
    int arr[n]; // размер известен в runtime
}
```

- Только на стеке и только локально.
- Опасно при больших `n` (переполнение стека).
- В C11 опционально (`__STDC_NO_VLA__`), в C23 снова обязательно.

### Типичные ошибки

- Выход за границы — UB, в C нет проверки.
- `sizeof` параметра-массива даёт размер указателя.
- Возврат массива из функции невозможен напрямую.
- `char s[5] = "hello";` — ошибка, нет места под `'\0'`.

## 6. Литералы

### Целочисленные

```c
42        // int
42u       // unsigned int
42l       // long
42ul      // unsigned long
42ll      // long long
42ull     // unsigned long long

0x2A      // шестнадцатеричный
052       // восьмеричный (= 42!)
0b101010  // двоичный (C23)
```

Опасность: `int x = 052;` — это **42**, а не 52. Ведущий ноль = восьмеричная запись.

### С плавающей точкой

```c
3.14      // double
3.14f     // float
3.14L     // long double
1e10      // double
0x1.8p3   // hex float (C99): 1.5 * 2^3 = 12.0
```

### Символьные

```c
'A'       // char, код 65
'\n'      // newline
'\t'      // tab
'\0'      // null
'\\'      // обратный слэш
'\''      // одинарная кавычка
'\x41'    // hex escape: 'A'
'\101'    // octal escape: 'A'
'\u00e9'  // universal character name (C99)
```

### Строковые

```c
"hello"           // char[6]
"a" "b" "c"       // конкатенация: "abc"
u8"utf-8"         // UTF-8 (C11)
u"utf-16"         // char16_t[]
U"utf-32"         // char32_t[]
L"wide"           // wchar_t[]
```

### Составные литералы (C99)

```c
(struct Point){ .x = 1, .y = 2 }
(int[]){ 1, 2, 3 }
```

### Логические (C99, `<stdbool.h>`)

```c
true   // 1
false  // 0
```

### `NULL`

```c
NULL  // обычно ((void*)0) или 0
```

Правила: для указателей — `NULL`, для символов — `'\0'`, для чисел — `0`.

### Опасности

- `1 / 2` — целочисленное деление, результат `0`.
- `1.0 / 2` — деление с плавающей точкой, `0.5`.
- `sizeof('A')` в C равен `sizeof(int)`. Историческая особенность.
- Восьмеричные литералы легко перепутать с десятичными.
- Суффиксы влияют на результат арифметики.

## 7. Преобразования типов

### Неявные

- Целые → целые: могут терять данные.
- Целые → плавающие: могут терять точность для больших значений.
- Плавающие → целые: **отбрасывается дробная часть** (не округление).
- `char`/`short` → `int` (целочисленные повышения).
- `float` → `double` в variadic-функциях.

```c
int i = 3.99;        // i == 3
double d = 1 / 2;    // d == 0.0
double e = 1.0 / 2;  // e == 0.5
```

### Явные (приведение)

```c
(int)3.99          // 3
(double)1 / 2      // 0.5
(char)300          // зависит от знаковости char
```

### Опасности

- Сужение типов без предупреждения.
- `int` → `unsigned` при отрицательных значениях.
- `size_t` (беззнаковый) vs `int` в циклах.
- `float` → `int` при значениях вне диапазона — UB.

### Компилятор в помощь

```
-Wconversion -Wsign-conversion -Werror
```

Предупредит о потенциально опасных преобразованиях.

## 8. Частые ошибки

1. Знаковое переполнение — UB.
2. Восьмеричные литералы (`052` = 42).
3. `sizeof` беззнаковый: `sizeof(x) - 1 > 0` может удивить.
4. `char` может быть знаковым: символы > 127 отрицательны.
5. Строки не сравниваются через `==`, только `strcmp`.
6. Изменять строковый литерал нельзя — UB.
7. Массив в параметре = указатель, размер теряется.
8. VLA опциональны в C11.
9. `enum` в C — целое, можно присвоить что угодно.
10. `0.1 + 0.2 != 0.3`, сравнивать `double` на равенство нельзя.
11. `float` в `printf` повышается до `double`. Для `scanf`: `%f` для `float`, `%lf` для `double`.
12. Порядок вычисления аргументов не определён: `f(i++, i++)` — UB.

## 9. Шпаргалка

```c
// Целые
int i = 42;
unsigned u = 42u;
long l = 42L;
long long ll = 42LL;
#include <stdint.h>
int32_t x = 42; uint64_t y = 42;

// Плавающие
float f = 3.14f;
double d = 3.14;
long double ld = 3.14L;
#include <math.h>
fabs(d); sqrt(d); isnan(d); isinf(d);

// Символы
char c = 'A';
char s[] = "hello";
const char *p = "world";

// Enum
enum Color { RED, GREEN, BLUE };
enum Color col = GREEN;

// Массивы
int a[10] = {0};
int b[] = {1, 2, 3};
size_t n = sizeof(b) / sizeof(b[0]);
int m[2][3] = {{1,2,3}, {4,5,6}};

// Литералы
42, 42u, 42L, 42LL
0x2A, 052, 0b101010
3.14, 3.14f, 3.14L, 1e10
'A', '\n', '\0', '\x41'
"str", "concat" "enated"
(struct P){ .x = 1 }

// Пределы
#include <limits.h>
INT_MAX, INT_MIN, UINT_MAX
#include <float.h>
DBL_MAX, DBL_EPSILON
```
