# Глава 1. Обзор языка C

## 1. Базовая структура программы
*   **Функции и переменные**: Программа на C состоит из функций и переменных. Функции содержат инструкции (вычисления), переменные хранят значения.
*   **`main`**: Особая функция. Любая программа начинается с первой инструкции `main`.
*   **Директивы препроцессора**: `#include <stdio.h>` подключает стандартную библиотеку ввода-вывода (I/O).
*   **Фигурные скобки `{}`**: Ограничивают тело функции или блок инструкций.
*   **Точка с запятой `;`**: Завершает любую инструкцию (statement).
*   **Комментарии**: `/* ... */` игнорируются компилятором.

## 2. Переменные и типы данных
*   **Объявление**: Все переменные должны быть объявлены до использования. Обычно в начале функции.
*   **Базовые типы**:
    *   `int` — целые числа (обычно 16 или 32 бита).
    *   `float` — числа с плавающей точкой (дробные).
    *   `char` — один байт (символ).
    *   `short`, `long`, `double` — вариации для увеличения диапазона/точности.
*   **Именованные константы (`#define`)**: Позволяют избежать «магических чисел» в коде.
    *   Синтаксис: `#define ИМЯ значение` (без `;` в конце!).
    *   По соглашению пишутся заглавными буквами (`LOWER`, `UPPER`).

## 3. Арифметика и операторы
*   **Целочисленное деление**: Важнейшая особенность! `5/9` всегда равно `0`, так как дробная часть отбрасывается. Для получения дробного результата нужно использовать `5.0/9.0`.
*   **Приоритет операторов**: Умножение/деление выше сложения/вычитания. Скобки меняют приоритет.
*   **Инкремент/Декремент**: `++nc` (увеличить на 1) и `--nc` (уменьшить на 1). Бывают префиксными (`++nc`) и постфиксными (`nc++`). В выражениях они имеют разный смысл (в главе 1 используется префиксная форма для счетчиков).
*   **Операторы сравнения**: `!=` (не равно), `==` (равно). **Важно:** `=` — это присваивание, `==` — сравнение. Их путаница — классическая ошибка новичков.

## 4. Управляющие конструкции
*   **`while (условие)`**: Проверяет условие *перед* выполнением тела. Если условие ложно изначально, тело не выполнится ни разу.
*   **`for (инициализация; условие; шаг)`**: Удобен, когда инициализация и шаг логически связаны. Эквивалентен `while`, но компактнее.
*   **`if (условие) ... else if (условие) ... else ...`**: Многопутевое ветвление.
*   **Логические операторы**: `&&` (И), `||` (ИЛИ). Обладают **коротким замыканием** (вычисления прекращаются, как только результат ясен). Приоритет `&&` выше, чем `||`.
*   **Пустая инструкция**: `;` (используется, когда тело цикла не нужно, например, в `for` для подсчета).

## 5. Ввод и вывод (I/O)
### Форматированный вывод (`printf`)
*   `%d` — целое десятичное.
*   `%f` — число с плавающей точкой.
*   `%s` — строка.
*   `%c` — символ.
*   `%o`, `%x` — восьмеричное, шестнадцатеричное.
*   **Ширина и точность**: `%3d` (поле из 3 позиций), `%6.1f` (поле 6, 1 знак после запятой).
*   **Эскейп-последовательности**: `\n` (новая строка), `\t` (табуляция), `\b` (забой), `\\` (обратный слэш), `\"` (кавычка).

### Посимвольный ввод/вывод (`getchar` / `putchar`)
*   **Модель потока**: Текст — это поток символов.
*   **`c = getchar()`**: Читает следующий символ из потока.
*   **`putchar(c)`**: Печатает символ.
*   **`EOF` (End Of File)**: Специальное значение, возвращаемое `getchar()`, когда поток исчерпан.
*   **Почему `int c`, а не `char c`?** `char` слишком мал, чтобы вместить все возможные символы *плюс* значение `EOF`. Поэтому используется `int`.
*   **Идиома C**: `while ((c = getchar()) != EOF)`
    *   Присваивание внутри условия. Скобки обязательны, так как приоритет `!=` выше, чем `=`. Без скобок `c` получило бы 0 или 1.

## 6. Массивы и строки
*   **Массивы**: `int ndigit[10];` — индексация начинается с **0**.
*   **Символы как целые**: `char` — это просто маленькое целое. `c - '0'` дает числовое значение цифры (например, `'5' - '0' = 5`).
*   **Строки**: В C нет типа «строка». Это массив символов, **обязательно заканчивающийся нулевым символом `\0`**.
*   **`'\0'`**: Маркер конца строки. Используется функциями `printf("%s")`, `copy` и другими.
*   **Разница**: `'x'` — это один символ (целое число). `"x"` — это строка (массив из `'x'` и `'\0'`).

## 7. Функции
*   **Определение**: `тип_результата имя(параметры) { тело }`.
*   **Прототип**: `int power(int m, int n);` — объявление функции до ее использования. Позволяет компилятору проверять типы аргументов.
*   **Параметры vs Аргументы**:
    *   *Параметры* — переменные в определении функции.
    *   *Аргументы* — значения, передаваемые при вызове.
*   **`return`**: Возвращает значение (или просто завершает функцию, если без выражения).
*   **`void`**: Если функция ничего не возвращает, используется тип `void` (например, `void copy(...)`).
*   **Вызов по значению (Call by Value)**: **Ключевая концепция C.** В функцию передаются *копии* значений аргументов. Изменение параметров внутри функции не влияет на оригинальные переменные в вызывающей функции. (Для изменения оригинала нужно передавать указатель, но это тема следующих глав).

## 8. Область видимости (Scope) и классы памяти
*   **Локальные (автоматические) переменные**:
    *   Объявлены внутри функции.
    *   Создаются при входе в функцию, уничтожаются при выходе.
    *   Не сохраняют значения между вызовами (содержат «мусор»).
    *   Доступны только внутри своей функции.
*   **Внешние (глобальные) переменные**:
    *   Определены вне функций.
    *   Доступны любой функции (если объявлены с `extern` или определены выше по файлу).
    *   Существуют всё время работы программы.
    *   **Осторожно**: Чрезмерное использование внешних переменных ведет к запутанному коду и трудностям при отладке. Лучше передавать данные через аргументы.
*   **`extern`**: Ключевое слово для *объявления* внешней переменной (сообщает компилятору, что она где-то определена, память под нее выделять не нужно).
*   **Заголовочные файлы (`.h`)**: Собирают прототипы функций и объявления внешних переменных для использования в нескольких `.c` файлах.

## 9. Практические примеры из главы (для запоминания)
1.  **Hello, world**: Базовая структура, `printf`.
2.  **Таблица температур**: `while`/`for`, `int` vs `float`, целочисленное деление, форматированный вывод.
3.  **Копирование файла**: `getchar`/`putchar`, `EOF`, идиома `while ((c = getchar()) != EOF)`.
4.  **Подсчет символов/строк/слов**: `long`, `++`, `if-else`, `||`/`&&`, `#define` для состояний (`IN`/`OUT`).
5.  **Гистограмма цифр**: Массивы, `c - '0'`, `switch` (в следующих главах).
6.  **Поиск самой длинной строки**: Работа со строками, `getline`, `copy`, `\0`, `void`, передача массивов в функции.

# Глава 2. Типы, операторы и выражения

## 1. Имена, типы и квалификаторы (Фундамент данных)

### 1.1. Правила именования
*   Первый символ — буква. Далее — буквы, цифры и `_`.
*   Регистрозависимы (`x` и `X` — разные).
*   **Значимость:** Для внутренних имен значимы первые 31 символ. Для внешних (функции, глобальные переменные) — только первые 6 символов (и регистр может не учитываться). Это ограничение линковщиков.
*   Не начинайте с `_` — это зарезервировано для библиотек.

### 1.2. Базовые типы и их размеры
*   `char` — 1 байт. Может быть `signed` или `unsigned` (зависит от машины). Всегда положителен для печатаемых символов.
*   `int` — естественный размер для машины (обычно 16 или 32 бита).
*   `short` >= 16 бит, `long` >= 32 бита. `short <= int <= long`.
*   `float`, `double`, `long double` — точность зависит от реализации.
*   **Квалификаторы:** `short`, `long`, `signed`, `unsigned`. `signed`/`unsigned` применяются к целым. `unsigned` работает по модулю 2^n.

### 1.3. `const` (Константность)
*   `const double e = 2.718;` — запрет на изменение.
*   `const char msg[] = "..."` — массив нельзя менять.
*   `int strlen(const char[]);` — функция обещает не менять массив.

---

## 2. Константы (Как записывать данные)

*   **Целые:** `1234` (int), `123456789L` (long), `123U` (unsigned), `0x1F` (hex), `037` (octal). Суффиксы: `U`, `L`, `UL`.
*   **Плавающие:** `123.4`, `1e-2` (double по умолчанию), `123.4f` (float), `1e-2L` (long double).
*   **Символьные:** `'A'` — это целое число (код ASCII, например, 65). Эскейп-последовательности: `\n`, `\t`, `\0`, `\ooo` (восьмеричный код), `\xhh` (шестнадцатеричный код).
*   **Строковые:** `"hello"` — массив символов, **всегда** заканчивающийся `\0`.
    *   `strlen(s)` считает символы до `\0` (не включая его).
    *   Конкатенация: `"hello" " world"` -> `"hello world"`.
*   **Перечисления (`enum`):** `enum boolean { NO, YES };` — NO = 0, YES = 1. Удобны для читаемости.

## 3. Операторы (Действия над данными)

### 3.1. Арифметические (`+ - * / %`)
*   **Целочисленное деление:** `5/9 == 0`. Дробная часть отбрасывается.
*   **Остаток `%`:** Работает только с целыми. `x % y` — остаток от деления.
*   **Приоритет:** `* / %` выше, чем `+ -`. Унарные `+ -` выше бинарных.

### 3.2. Отношения и логика (`> >= < <= == != && || !`)
*   Результат — всегда `1` (истина) или `0` (ложь).
*   **Короткое замыкание (Short-circuit):** Вычисление `&&` и `||` прекращается, как только результат ясен.
    *   **Применение в I/O (из Главы 1):**
        ```c
        for (i = 0; i < lim-1 && (c = getchar()) != EOF && c != '\n'; ++i)
        ```
        Здесь порядок критичен: сначала проверяем место в буфере, потом читаем символ, потом проверяем на конец файла/строки. Если места нет, `getchar()` даже не вызовется.
*   **Приоритет:** `&&` выше, чем `||`. Оба ниже, чем операторы сравнения.

### 3.3. Побитовые операторы (`& | ^ << >> ~`)
*   **`&` (И):** Маскирование (обнуление) битов. `n = n & 0177;` (оставить младшие 7 бит).
*   **`|` (ИЛИ):** Установка битов. `x = x | SET_ON;`
*   **`^` (Исключающее ИЛИ):** Инверсия битов по маске.
*   **`<<` / `>>`:** Сдвиг. `x << 2` — умножение на 4. `x >> 2` — деление на 4.
    *   **Ловушка:** Сдвиг вправо для `signed` чисел зависит от машины (арифметический сдвиг с сохранением знака или логический с нулями). Для переносимости используйте `unsigned`.
*   **`~`:** Побитовое отрицание. `~0` — все единицы.
*   **Практика (Функция `getbits`):**
    ```c
    unsigned getbits(unsigned x, int p, int n) {
        return (x >> (p+1-n)) & ~(~0 << n);
    }
    ```
    *   `x >> (p+1-n)` — сдвигает нужное поле к правому краю.
    *   `~(~0 << n)` — создает маску из `n` единиц справа. `~0` — все единицы, сдвиг влево на `n` дает нули справа, инверсия возвращает единицы.

### 3.4. Инкремент и декремент (`++`, `--`)
*   **Префиксный `++n`:** Сначала увеличивает, потом возвращает.
*   **Постфиксный `n++`:** Сначала возвращает, потом увеличивает.
*   **Практика:** `s[j++] = s[i];` — классическая идиома копирования с одновременным сдвигом индекса.
*   **Ограничение:** Применяются только к переменным. `(i+j)++` — ошибка.

### 3.5. Присваивание (`op=`)
*   `i += 2` эквивалентно `i = i + 2`.
*   `x *= y + 1` эквивалентно `x = x * (y + 1)`. Скобки важны!
*   Левая часть вычисляется только один раз (важно для сложных выражений).

### 3.6. Условное выражение (`? :`)
*   `z = (a > b) ? a : b;` — тернарный оператор.
*   Вычисляется только одна из ветвей `?` или `:`.
*   Тип результата определяется по правилам преобразования типов (например, `float` и `int` дадут `float`).

---

## 4. Преобразования типов (Правила игры)

### 4.1. Неявные преобразования (Автоматические)
*   **Повышение (Promotion):** Если операнды разных типов, «младший» приводится к «старшему».
    *   `char`, `short` -> `int` (в арифметических выражениях).
    *   `int` -> `float` -> `double` -> `long double`.
*   **Правила:**
    1. Если есть `long double` -> все к `long double`.
    2. Иначе если есть `double` -> все к `double`.
    3. Иначе если есть `float` -> все к `float`.
    4. Иначе `char`/`short` -> `int`.
    5. Иначе если есть `long` -> все к `long`.
*   **Ловушка `char`:** `char` может быть знаковым или беззнаковым. При преобразовании в `int` может произойти расширение знака (отрицательное число) или добавление нулей. Для не-символьных данных используйте `signed char` или `unsigned char`.

### 4.2. Явные преобразования (Приведение, Cast)
*   `(double) n` — приводит `n` к `double`, но не меняет саму переменную `n`.
*   **Пример (Функция `atoi`):**
    ```c
    int atoi(char s[]) {
        int i, n = 0;
        for (i = 0; s[i] >= '0' && s[i] <= '9'; ++i)
            n = 10 * n + (s[i] - '0');
        return n;
    }
    ```
    Здесь `s[i] - '0'` дает числовое значение цифры (например, `'5' - '0' = 5`).

### 4.3. Ловушка `unsigned` и `signed`
*   Сравнение знаковых и беззнаковых чисел может дать неожиданный результат.
*   Пример (при 16-битном `int` и 32-битном `long`):
    *   `-1L < 1U` -> Истина (1U повышается до `signed long`).
    *   `-1L > 1UL` -> Истина (`-1L` повышается до `unsigned long` и становится огромным положительным числом).

---

## 5. Приоритет и очередность вычислений (Самое опасное)

### 5.1. Таблица приоритетов (От высшего к низшему)
1.  `()` `[]` `->` `.` (слева направо)
2.  `!` `~` `++` `--` `+` `-` `*` `&` `(type)` `sizeof` (справа налево)
3.  `*` `/` `%` (слева направо)
4.  `+` `-` (слева направо)
5.  `<<` `>>` (слева направо)
6.  `<` `<=` `>` `>=` (слева направо)
7.  `==` `!=` (слева направо)
8.  `&` (слева направо)
9.  `^` (слева направо)
10. `|` (слева направо)
11. `&&` (слева направо)
12. `||` (слева направо)
13. `? :` (справа налево)
14. `=` `+=` `-=` `*=` `/=` `%=` `&=` `^=` `|=` `<<=` `>>=` (справа налево)
15. `,` (слева направо)

*   **Важно:** Побитовые операторы `&`, `^`, `|` имеют **более низкий** приоритет, чем `==` и `!=`. Поэтому `if ((x & MASK) == 0)` требует скобок.

### 5.2. Порядок вычислений (Order of Evaluation)
*   C **не** гарантирует порядок вычисления операндов (кроме `&&`, `||`, `?:`, `,`).
*   **Пример опасности:**
    ```c
    x = f() + g(); // f() может быть вызвана до g(), а может и после.
    ```
*   **Побочные эффекты (Side Effects):**
    ```c
    printf("%d %d\n", ++n, power(2, n)); // НЕПРАВИЛЬНО! Зависит от компилятора.
    a[i] = i++; // НЕПРАВИЛЬНО! Неопределенное поведение.
    ```
*   **Мораль:** Не пишите код, который зависит от порядка вычислений. Если сомневаетесь — используйте временные переменные.

# Глава 3. Управление 

## 1. Инструкции и блоки (Фундамент синтаксиса)
*   **Инструкция (Statement):** Любое выражение, заканчивающееся `;`. Точка с запятой — это **терминатор**, а не разделитель (в отличие от Паскаля). Пустая инструкция `;` — это тоже инструкция.
*   **Блок (Block):** `{ ... }`. Объединяет объявления и инструкции в одну составную инструкцию. Синтаксически блок эквивалентен одной инструкции. После закрывающей `}` точка с запятой **не ставится**.
*   **Зачем нужны блоки?** Для группировки нескольких действий там, где синтаксис требует одну инструкцию (например, тело `if`, `while`, `for`).

## 2. Ветвление: if-else и else-if (Принятие решений)

### 2.1. `if-else`
*   **Синтаксис:** `if (выражение) инструкция1 else инструкция2`
*   **Механика:** Вычисляется выражение. Если оно **не ноль** (истина) -> выполняется `инструкция1`. Если **ноль** (ложь) и есть `else` -> выполняется `инструкция2`.
*   **Сокращенная запись:** `if (x)` эквивалентно `if (x != 0)`.

### 2.2. Ловушка «Висячего else» (Dangling Else)
*   **Проблема:** `else` всегда связывается с **ближайшим** `if`, у которого нет своего `else`.
    ```c
    if (n > 0)
        if (a > b)
            z = a;
    else // Этот else относится к if (a > b), а не к if (n > 0)!
        z = b;
    ```
*   **Решение:** Всегда используйте фигурные скобки `{}` для вложенных `if`, если есть малейшие сомнения. Это избавляет от неоднозначности и облегчает чтение.

### 2.3. Конструкция `else-if` (Многопутевое ветвление)
*   **Синтаксис:**
    ```c
    if (условие1) инструкция1;
    else if (условие2) инструкция2;
    else if (условие3) инструкция3;
    else инструкция_по_умолчанию;
    ```
*   **Механика:** Проверки идут сверху вниз. Как только условие истинно, выполняется соответствующая инструкция, и вся конструкция завершается.
*   **Пример (Бинарный поиск, `binsearch`):** Классический пример `else-if`. Сравниваем `x` с серединой массива. Если меньше — ищем в левой половине, если больше — в правой, если равно — возвращаем индекс. Логарифмическая сложность O(log n).

## 3. Множественный выбор: `switch`

*   **Назначение:** Выбор одной из многих ветвей на основе **целочисленного** выражения.
*   **Синтаксис:**
    ```c
    switch (выражение) {
        case конст1: инструкции; break;
        case конст2: инструкции; break;
        default: инструкции; break;
    }
    ```
*   **Ограничения:**
    *   `выражение` должно быть целочисленного типа (`int`, `char`, `enum`).
    *   `конст` должны быть **целочисленными константами** или константными выражениями. Переменные использовать нельзя.
    *   Все константы должны быть уникальны.
*   **Механика «Провала» (Fall-through):** Если не поставить `break`, выполнение «провалится» в следующую ветку `case`.
    *   **Полезное применение:** Группировка нескольких случаев.
        ```c
        case '0': case '1': case '2': // Все эти случаи делают одно и то же
            ndigit[c - '0']++;
            break;
        ```
    *   **Опасность:** Забытый `break` — это классическая ошибка, которая приводит к трудноуловимым багам. **Правило:** Всегда ставьте `break` в конце каждой ветки, кроме случаев намеренной группировки.
*   **`default`:** Выполняется, если ни одна из констант не совпала. Можно располагать в любом месте, но обычно ставят в конце.

## 4. Циклы: while, for, do-while

### 4.1. `while` и `for` (Циклы с предусловием)
*   **`while (выражение) инструкция`**: Проверка условия перед каждой итерацией. Может не выполниться ни разу.
*   **`for (выр1; выр2; выр3) инструкция`**:
    *   **Эквивалентен:** `выр1; while (выр2) { инструкция; выр3; }`
    *   **Механика:** `выр1` (инициализация) выполняется один раз. `выр2` (условие) проверяется перед каждой итерацией. `выр3` (шаг) выполняется после каждой итерации.
    *   **Любое из трех выражений может отсутствовать.** `for (;;)` — бесконечный цикл. Точки с запятой обязательны.
*   **Выбор между `while` и `for`:**
    *   `for` — когда есть простая инициализация и шаг (арифметическая прогрессия).
    *   `while` — когда инициализации/шага нет, или условие сложное (например, `while ((c = getchar()) == ' ')`).

### 4.2. Оператор «запятая» (`,`) в циклах
*   **Механика:** Выражения, разделенные запятой, вычисляются **слева направо**. Результат — значение **правого** выражения.
*   **Применение:** Позволяет вести два и более индекса параллельно в заголовке `for`.
    ```c
    for (i = 0, j = strlen(s)-1; i < j; i++, j--) { ... }
    ```
*   **Важно:** Запятые в аргументах функций и объявлениях переменных — это **не** оператор запятая.

### 4.3. `do-while` (Цикл с постусловием)
*   **Синтаксис:** `do инструкция while (выражение);`
*   **Механика:** Тело выполняется **хотя бы один раз**, затем проверяется условие. Если истина — повтор.
*   **Когда использовать:** Когда тело цикла должно выполниться минимум один раз, даже если условие изначально ложно.
*   **Пример (`itoa`):** Преобразование числа в строку. Даже если `n = 0`, нужно сгенерировать символ `'0'`.
    ```c
    do {
        s[i++] = n % 10 + '0'; // Генерируем цифру
    } while ((n /= 10) > 0);    // Отбрасываем её
    ```
    *Ловушка `itoa`*: Проблема с `-(2^n-1)` (самое большое по модулю отрицательное число). `n = -n` вызывает переполнение. Решается через `unsigned`.

## 5. Инструкции break, continue, goto

### 5.1. `break`
*   **Действие:** Немедленный выход из **самого внутреннего** цикла (`for`, `while`, `do-while`) или `switch`.
*   **Применение:** Выход из цикла по дополнительному условию, которое сложно проверить в заголовке.
*   **Пример (`trim`):** Удаление завершающих пробелов. Идем с конца строки, пока не встретим непробельный символ. Как только нашли — `break`.

### 5.2. `continue`
*   **Действие:** Прерывает текущую итерацию и переходит к **следующей**.
    *   Для `while`/`do-while`: немедленный переход к проверке условия.
    *   Для `for`: переход к шагу (`выр3`), затем к проверке условия.
*   **Применение:** Пропуск части тела цикла при определенных условиях (например, пропуск отрицательных элементов массива).
*   **Важно:** Не работает для `switch` (вызовет переход к следующей итерации объемлющего цикла).

### 5.3. `goto` и метки
*   **Синтаксис:** `goto метка;` ... `метка: инструкция;`
*   **Отношение:** Порицается, так как ведет к «спагетти-коду».
*   **Единственное оправданное применение:** Выход из **глубоко вложенных** циклов, когда `break` не справляется (выходит только из самого внутреннего).
    ```c
    for (...) 
        for (...) {
            if (disaster) goto error;
        }
    error:
        // обработка ошибки
    ```

# Глава 4. Функции и структура программы 

## 1. Архитектура программы: Раздельная компиляция и Заголовочные файлы

Программа на C — это набор внешних объектов (функций и переменных). Их можно компилировать по отдельности и связывать вместе.

### 1.1. Раздельная компиляция
*   Исходный код можно разбить на несколько файлов (`.c`).
*   Компиляция: `cc main.c getline.c strindex.c` создает объектные файлы (`main.o`, `getline.o`, `strindex.o`) и линкует их в исполняемый файл (`a.out`).
*   Если изменился только один файл, перекомпилируется только он, а остальные берутся из `.o`. Это **ключевое преимущество** для больших проектов.
*   **Правило:** Ни одна функция не может быть разрезана между файлами.

### 1.2. Заголовочные файлы (Header Files, `.h`)
*   **Проблема:** Если функция определена в одном файле, а используется в другом, компилятор должен знать её прототип (тип возврата и аргументы).
*   **Решение:** Создать `calc.h` и включать его через `#include "calc.h"`.
*   **Правило:** В заголовочном файле должны быть **только объявления** (прототипы функций, `extern` переменные), но **не определения** (тела функций, выделение памяти).
*   **Стандартные заголовки:** `<stdio.h>` — для I/O, `<ctype.h>` — для работы с символами (`isdigit`, `isspace`), `<stdlib.h>` — для `atof`, `atoi`.

### 1.3. Определение vs Объявление (Definition vs Declaration)
*   **Определение:** Создает объект, выделяет память. `int sp; double val[MAXVAL];` (вне функций).
*   **Объявление:** Сообщает компилятору свойства объекта, память не выделяет. `extern int sp; extern double val[];`.
*   **Правило одного определения:** На всю программу (все файлы) для каждой внешней переменной должно быть **ровно одно** определение. Остальные файлы используют `extern`.

---

## 2. Области видимости и Классы памяти (Storage Classes)

### 2.1. Внешние переменные (External Variables)
*   Доступны любой функции, если объявлены (`extern`).
*   Используются для связи между функциями без длинных списков аргументов.
*   **Опасность:** Чрезмерное использование ведет к «спагетти-коду» и трудностям отладки. Лучше передавать данные через аргументы.

### 2.2. Статические переменные (`static`)
*   **Для глобальных переменных и функций:** Ограничивает область видимости **пределами одного файла**. Скрывает имена от линковщика.
    *   *Применение:* Переменные `buf`, `bufp`, `sp`, `val` в калькуляторе. Функции `push` и `pop` видят их, а `main` — нет.
*   **Для локальных переменных:** Переменная не создается и не уничтожается при входе/выходе из функции. Она существует **постоянно**, сохраняя значение между вызовами.
    *   *Применение:* Счетчики, буферы, кэши внутри функции.

### 2.3. Регистровые переменные (`register`)
*   Подсказка компилятору: «Эта переменная будет использоваться интенсивно, помести её в регистр процессора».
*   Компилятор может проигнорировать.
*   **Ограничение:** К регистровой переменной **нельзя применить оператор `&`** (взять адрес).
*   Применяется только к автоматическим переменным и параметрам функций.

### 2.4. Блочная структура (Block Scope)
*   Переменные можно объявлять внутри любого блока `{}`.
*   Они «затеняют» (shadow) переменные с тем же именем во внешних блоках.
*   *Пример:* `if (n > 0) { int i; for (i = 0; ...) }`. Переменная `i` существует только внутри `if`.

### 2.5. Инициализация (Initialization Rules)
*   **Внешние и статические:** Инициализируются **нулями** по умолчанию. Инициализация происходит **один раз** до начала программы.
*   **Автоматические и регистровые:** Содержат **«мусор»** по умолчанию. Инициализируются **каждый раз** при входе в функцию/блок.
*   **Массивы:** `int days[] = {31, 28, ...};`. Если размер не указан, вычисляется по количеству инициализаторов.
*   **Строки:** `char pattern[] = "ould";` — эквивалентно `{'o','u','l','d','\0'}`.

## 3. Рекурсия (Recursion)

*   Функция может вызывать саму себя.
*   **Механика:** Каждый вызов создает **новый набор автоматических переменных** (новый кадр стека). Предыдущие значения сохраняются.
*   **Примеры:**
    *   `printd(n)`: Печатает число, рекурсивно вызывая себя для старших цифр, затем печатает младшую.
    *   `qsort(v, left, right)`: Быстрая сортировка. Выбирает опорный элемент, разделяет массив и рекурсивно сортирует подмассивы.
*   **Плюсы:** Компактный, элегантный код для рекурсивных структур (деревья).
*   **Минусы:** Расход памяти на стек, накладные расходы на вызовы.

## 4. Мастер-класс: Калькулятор с обратной польской записью (RPN)

Это **главный практический пример** главы, демонстрирующий комбинирование всех механик: I/O, массивов, внешних переменных, `switch` и функций.

### 4.1. Логика RPN
*   Операнды кладутся в стек.
*   Оператор берет операнды из стека, вычисляет результат и кладет его обратно.
*   `(1 - 2) * (4 + 5)` -> `1 2 - 4 5 + *`.
*   **Механика:** `main` использует `switch` для обработки типов токенов.

### 4.2. Стек (Внешние переменные)
```c
#define MAXVAL 100
int sp = 0;          // Внешняя переменная (индекс вершины)
double val[MAXVAL];  // Внешняя переменная (массив-стек)
```
*   `push(double f)`: Кладет значение, увеличивает `sp`.
*   `pop(void)`: Возвращает значение, уменьшает `sp`.
*   `main` не видит `sp` и `val` напрямую, он использует только `push` и `pop`.

### 4.3. Буферизация ввода: `getch` и `ungetch` (Критически важно!)
*   **Проблема:** Чтобы распарсить число, нужно прочитать символ, который **не является** частью числа (например, пробел или оператор). Этот символ уже прочитан из потока, и его нельзя потерять.
*   **Решение:** Механизм «возврата» символа во входной поток.
    ```c
    #define BUFSIZE 100
    char buf[BUFSIZE]; // Буфер для возвращенных символов
    int bufp = 0;      // Следующая свободная позиция в buf

    int getch(void) {
        return (bufp > 0) ? buf[--bufp] : getchar();
    }

    void ungetch(int c) {
        if (bufp >= BUFSIZE)
            printf("ungetch: слишком много символов\n");
        else
            buf[bufp++] = c;
    }
    ```
*   **Механика:** `getch` сначала проверяет буфер `buf`. Если там есть символы (возвращенные ранее), он берет их оттуда. Если буфер пуст — вызывает `getchar()`. `ungetch` просто кладет символ в буфер.
*   **Применение в `getop`:** `getop` читает символы, накапливает цифры в строку. Как только встречает не-цифру, он вызывает `ungetch(c)`, чтобы вернуть этот символ в поток. В следующий раз `getop` прочитает его снова.

### 4.4. Функция `getop` (Парсер)
*   Пропускает пробелы и табуляции.
*   Если символ — не цифра и не точка, возвращает его (это оператор).
*   Если цифра — накапливает строку цифр (целая и дробная часть), возвращает `NUMBER`.
*   `ungetch(c)` используется для возврата первого символа, который не является частью числа.

## 5. Препроцессор C (The C Preprocessor)

Препроцессор работает **до** компиляции. Он манипулирует текстом программы.

### 5.1. `#include`
*   `#include <stdio.h>` — поиск в системных директориях.
*   `#include "calc.h"` — поиск в текущей директории.
*   **Вложенность:** Файлы могут включать другие файлы.

### 5.2. `#define` (Макросы)
*   **Простые:** `#define MAXLINE 1000`. Текстовая замена.
*   **С аргументами:** `#define max(A, B) ((A) > (B) ? (A) : (B))`.
*   **ЛОВУШКИ МАКРОСОВ:**
    1.  **Двойное вычисление:** `max(i++, j++)` увеличит `i` и `j` дважды! (Опасно с побочными эффектами).
    2.  **Отсутствие скобок:** `#define square(x) x*x`. Вызов `square(z+1)` развернется в `z+1*z+1`, что неверно. Нужно `((x)*(x))`.
*   **Оператор `#`:** Превращает аргумент макроса в строку. `#define dprint(expr) printf(#expr " = %g\n", expr)`. `dprint(x/y)` -> `printf("x/y" " = %g\n", x/y)`.
*   **Оператор `##`:** Конкатенация (склеивание) токенов. `#define paste(front, back) front ## back`. `paste(name, 1)` -> `name1`.
*   **`#undef`:** Отменяет определение макроса.

### 5.3. Условная компиляция
*   `#if`, `#elif`, `#else`, `#endif`.
*   `defined(NAME)` — истина, если NAME определен.
*   **Защита от повторного включения (Header Guards):**
    ```c
    #ifndef HDR
    #define HDR
    /* Содержимое hdr.h */
    #endif
    ```
    Это предотвращает многократное включение одного и того же файла, что вызывает ошибки «повторного определения».

# Глава 5. Указатели и массивы (Глубокий конспект)
---

## 1. Указатели и адреса

**Указатель** — переменная, хранящая адрес другой переменной.  
**Оператор `&`** — взятие адреса (применим только к объектам в памяти: переменным, элементам массивов; не к выражениям, константам, регистровым переменным).  
**Оператор `*`** — косвенное обращение (разыменование): выдаёт объект по адресу.

```c
int x = 1, y = 2, z[10];
int *ip;        // ip — указатель на int
ip = &x;        // ip указывает на x
y = *ip;        // y = 1
*ip = 0;        // x = 0
ip = &z[0];     // ip указывает на z[0]
```

**Объявление указателя:** `int *ip;` читается как «выражение `*ip` имеет тип `int`».  
**Приоритет:** `*` и `&` имеют высокий приоритет (как унарные).  
`*ip += 1` увеличивает то, на что указывает ip.  
`(*ip)++` — скобки обязательны, иначе увеличится сам указатель.  
`iq = ip` копирует адрес, теперь оба указывают на один объект.

---

## 2. Указатели и аргументы функций

В C аргументы передаются **по значению**. Чтобы функция могла изменить переменную вызывающей стороны, нужно передать **указатель** на неё.

**Пример: swap**
```c
void swap(int *px, int *py) {
    int temp = *px;
    *px = *py;
    *py = temp;
}
// вызов: swap(&a, &b);
```

**Пример: getint**
```c
int getint(int *pn) {
    int c, sign;
    while (isspace(c = getch()));
    if (!isdigit(c) && c != EOF && c != '+' && c != '-') {
        ungetch(c); return 0;
    }
    sign = (c == '-') ? -1 : 1;
    if (c == '+' || c == '-') c = getch();
    for (*pn = 0; isdigit(c); c = getch())
        *pn = 10 * *pn + (c - '0');
    *pn *= sign;
    if (c != EOF) ungetch(c);
    return c;
}
```
Здесь `pn` — указатель на int, куда записывается результат. Возврат: EOF, 0 (не число) или положительное (число).

---

## 3. Указатели и массивы

**Ключевая эквивалентность:**  
`a[i]` полностью эквивалентно `*(a + i)`.  
`&a[i]` эквивалентно `a + i`.

Имя массива — это **указатель на его нулевой элемент** (но не переменная, его нельзя менять: `a = pa` или `a++` запрещены).

```c
int a[10];
int *pa = a;        // или &a[0]
x = *pa;            // a[0]
x = *(pa+1);        // a[1]
x = *(a+1);         // a[1]
```

**Передача массива в функцию:**  
`char s[]` и `char *s` в параметрах эквивалентны. Функция получает копию указателя, но может изменять элементы массива.

**Пример: strlen через указатель**
```c
int strlen(char *s) {
    int n;
    for (n = 0; *s != '\0'; s++)
        n++;
    return n;
}
```
`s++` изменяет только локальную копию указателя.

---

## 4. Адресная арифметика

Допустимы следующие операции с указателями:
- присваивание указателя того же типа;
- сложение/вычитание указателя и целого (`p + n`, `p - n`);
- вычитание двух указателей на элементы одного массива (`p - q` даёт число элементов);
- сравнение указателей (`==`, `!=`, `<`, `>=` и т.д.) для элементов одного массива;
- присваивание нуля (`NULL`) и сравнение с ним.

**Недопустимо:** складывать два указателя, умножать, делить, сдвигать, применять к float/double, присваивать указатель одного типа другому без приведения (кроме `void*`).

**Пример: простейший распределитель памяти**
```c
#define ALLOCSIZE 10000
static char allocbuf[ALLOCSIZE];
static char *allocp = allocbuf;

char *alloc(int n) {
    if (allocbuf + ALLOCSIZE - allocp >= n) {
        allocp += n;
        return allocp - n;
    } else
        return 0;
}

void afree(char *p) {
    if (p >= allocbuf && p < allocbuf + ALLOCSIZE)
        allocp = p;
}
```
`alloc` возвращает указатель на блок из n символов или NULL (0).

**Размер шага:** `p++` увеличивает адрес на `sizeof(*p)`. Для `int*` — на 4 байта (обычно), для `char*` — на 1.

**Разность указателей:** `p - q` даёт количество элементов между p и q (тип `ptrdiff_t`).

## 5. Символьные указатели и функции

Строковая константа `"hello"` — это массив символов, заканчивающийся `'\0'`. Доступ к ней — через указатель на первый символ.

**Различие:**
```c
char amessage[] = "now is the time";  // массив, можно менять содержимое
char *pmessage = "now is the time";   // указатель на константу, менять содержимое нельзя
```

**Классические реализации строковых функций через указатели:**

```c
// strcpy: копирует t в s
void strcpy(char *s, char *t) {
    while (*s++ = *t++);
}
```
Здесь `*t++` возвращает символ до увеличения указателя, `*s++` записывает его и увеличивает s. Цикл завершается, когда скопирован `'\0'` (ложь).

```c
// strcmp: сравнивает s и t
int strcmp(char *s, char *t) {
    for ( ; *s == *t; s++, t++)
        if (*s == '\0') return 0;
    return *s - *t;
}
```

**Идиомы:**
- `*p++ = val;` — положить в стек.
- `val = *--p;` — взять из стека.

## 6. Массивы указателей, указатели на указатели

**Массив указателей:** `char *lineptr[MAXLINES];` — каждый элемент — указатель на char.

**Пример: сортировка строк**
```c
#define MAXLINES 5000
char *lineptr[MAXLINES];

int readlines(char *lineptr[], int nlines);
void writelines(char *lineptr[], int nlines);
void qsort(char *lineptr[], int left, int right);

int main() {
    int nlines;
    if ((nlines = readlines(lineptr, MAXLINES)) >= 0) {
        qsort(lineptr, 0, nlines-1);
        writelines(lineptr, nlines);
        return 0;
    } else {
        printf("error: too many lines\n");
        return 1;
    }
}
```

`readlines` читает строки, выделяет память через `alloc`, сохраняет указатели в `lineptr`.
`qsort` сортирует массив указателей, используя `strcmp`.
`swap` меняет местами указатели, а не сами строки.

**Указатель на указатель:** `char **argv` — используется в аргументах командной строки.

## 7. Многомерные массивы

**Двумерный массив:** `int daytab[2][13];`  
В памяти располагается построчно. `daytab[i][j]` — элемент i-й строки, j-го столбца.  
При передаче в функцию нужно указывать число столбцов: `f(int daytab[][13])` или `f(int (*daytab)[13])`.

**Инициализация:**
```c
static char daytab[2][13] = {
    {0,31,28,31,30,31,30,31,31,30,31,30,31},
    {0,31,29,31,30,31,30,31,31,30,31,30,31}
};
```

**Пример: day_of_year и month_day**
```c
int day_of_year(int year, int month, int day) {
    int i, leap;
    leap = (year%4 == 0 && year%100 != 0) || year%400 == 0;
    for (i = 1; i < month; i++)
        day += daytab[leap][i];
    return day;
}
void month_day(int year, int yearday, int *pmonth, int *pday) {
    int i, leap;
    leap = (year%4 == 0 && year%100 != 0) || year%400 == 0;
    for (i = 1; yearday > daytab[leap][i]; i++)
        yearday -= daytab[leap][i];
    *pmonth = i;
    *pday = yearday;
}
```

## 8. Инициализация массивов указателей

```c
char *month_name(int n) {
    static char *name[] = {
        "Illegal month", "January", "February", "March",
        "April", "May", "June", "July", "August", "September",
        "October", "November", "December"
    };
    return (n < 1 || n > 12) ? name[0] : name[n];
}
```
`name` — массив указателей на строки. Строки могут быть разной длины. Компилятор сам подсчитывает размер массива.

## 9. Указатели против многомерных массивов

```c
int a[10][20];   // истинно двумерный массив: 200 int, прямоугольный
int *b[10];      // массив из 10 указателей, каждый может указывать на разное количество int
```
`a` требует выделения 200*sizeof(int) памяти.  
`b` требует 10 указателей + память для строк (если инициализировать). Строки могут быть разной длины.

**Преимущество массива указателей:** гибкость, экономия памяти для строк разной длины.

## 10. Аргументы командной строки

`main(int argc, char *argv[])`  
`argc` — количество аргументов, `argv` — массив указателей на строки. `argv[0]` — имя программы, `argv[argc] == NULL`.

**Пример: echo**
```c
int main(int argc, char *argv[]) {
    while (--argc > 0)
        printf("%s%s", *++argv, (argc > 1) ? " " : "");
    printf("\n");
    return 0;
}
```

**Пример: find с опциями -x -n**
```c
int main(int argc, char *argv[]) {
    char line[MAXLINE];
    long lineno = 0;
    int c, except = 0, number = 0, found = 0;
    while (--argc > 0 && (*++argv)[0] == '-')
        while (c = *++argv[0])
            switch (c) {
                case 'x': except = 1; break;
                case 'n': number = 1; break;
                default: printf("find: illegal option %c\n", c);
                         argc = 0; found = -1; break;
            }
    if (argc != 1)
        printf("Usage: find -x -n pattern\n");
    else
        while (getline(line, MAXLINE) > 0) {
            lineno++;
            if ((strstr(line, *argv) != NULL) != except) {
                if (number) printf("%ld:", lineno);
                printf("%s", line);
                found++;
            }
        }
    return found;
}
```

## 11. Указатели на функции

Указатель на функцию хранит адрес кода функции. Позволяет передавать функции как аргументы, создавать таблицы функций и т.д.

**Пример: универсальная сортировка**
```c
void qsort(void *v[], int left, int right,
           int (*comp)(void *, void *)) {
    int i, last;
    void swap(void *v[], int, int);
    if (left >= right) return;
    swap(v, left, (left + right)/2);
    last = left;
    for (i = left+1; i <= right; i++)
        if ((*comp)(v[i], v[left]) < 0)
            swap(v, ++last, i);
    swap(v, left, last);
    qsort(v, left, last-1, comp);
    qsort(v, last+1, right, comp);
}
```

**Вызов:**
```c
qsort((void**)lineptr, 0, nlines-1,
      (int (*)(void*,void*))(numeric ? numcmp : strcmp));
```

**Функции сравнения:**
```c
int numcmp(char *s1, char *s2) {
    double v1 = atof(s1), v2 = atof(s2);
    if (v1 < v2) return -1;
    else if (v1 > v2) return 1;
    else return 0;
}
```

**Объявление указателя на функцию:**
```c
int (*comp)(void *, void *);  // comp — указатель на функцию
```
Без скобок `int *comp(void*, void*)` — функция, возвращающая указатель на int.

## 12. Сложные объявления

Синтаксис объявлений в C может быть сложным. Правило: читать от имени переменной, учитывая приоритеты (`()` и `[]` выше `*`).

**Примеры:**
```c
int *f();          // f — функция, возвращающая указатель на int
int (*pf)();       // pf — указатель на функцию, возвращающую int
char **argv;       // argv — указатель на указатель на char
int (*daytab)[13]; // daytab — указатель на массив из 13 int
```

**Инструмент:** программа `cdecl` преобразует объявления в словесное описание и обратно.

**Совет:** используйте `typedef` для упрощения сложных типов.

## 13. Ключевые механики и ловушки

1. **`*p++` vs `(*p)++`** — первый увеличивает указатель, второй — значение.
2. **Имя массива — не переменная:** нельзя `a = p`, `a++`.
3. **Передача массива в функцию** — передаётся указатель на первый элемент, размер не передаётся.
4. **Адресная арифметика** учитывает размер типа: `p+1` сдвигает на `sizeof(*p)` байт.
5. **Сравнение указателей** допустимо только для элементов одного массива.
6. **`void*`** — обобщённый указатель, может хранить любой адрес, но разыменовывать нельзя.
7. **Указатели на функции** позволяют реализовать полиморфизм и обратные вызовы.
8. **Массивы указателей** эффективнее двумерных массивов для строк разной длины.
9. **`argc`/`argv`** — стандартный способ получения аргументов командной строки.
10. **`NULL`** — нулевой указатель, определён в `<stdio.h>` (и других).

# Структуры 

**Структура** — это одна или несколько переменных, возможно разных типов, сгруппированных под одним именем. В Паскале аналогичная конструкция называется **записью**.

Структуры нужны для организации сложных данных: они позволяют рассматривать группу связанных переменных как единое целое. Примеры:

- строка платежной ведомости: имя, адрес, номер социального страхования, зарплата;
- графическая точка: пара координат `(x, y)`;
- прямоугольник: пара точек.

Стандарт ANSI C ввёл для структур:

- операцию присваивания;
- копирование структур;
- передачу структур в функции;
- возврат структур из функций;
- инициализацию автоматических структур и массивов.

---

## 2. Основные сведения о структурах

### Объявление

```c
struct point {
    int x;
    int y;
};
```

- `struct` — ключевое слово.
- `point` — **тег** структуры.
- `x`, `y` — **элементы** (members) структуры.
- Имена элементов и тегов могут совпадать с именами обычных переменных: они различаются по контексту.
- Одинаковые имена элементов могут встречаться в разных структурах, но хороший стиль — давать одинаковые имена только близким по смыслу объектам.

### Объявление переменных

```c
struct point pt;
struct { int x; int y; } x, y, z;
```

Последняя запись синтаксически аналогична:

```c
int x, y, z;
```

Объявление структуры без списка переменных не резервирует память — это только шаблон.

### Инициализация

```c
struct point maxpt = { 320, 200 };
```

Автоматические структуры можно инициализировать присваиванием или значением, возвращённым функцией.

### Доступ к элементам

```c
pt.x
pt.y
printf("%d,%d", pt.x, pt.y);
```

Пример вычисления расстояния от начала координат:

```c
double dist, sqrt(double);
dist = sqrt((double)pt.x * pt.x + (double)pt.y * pt.y);
```

### Вложенные структуры

Прямоугольник можно представить парой точек:

```c
struct rect {
    struct point pt1;
    struct point pt2;
};
```

Если объявить `struct rect screen;`, то доступ к координате:

```c
screen.pt1.x
```

---

## 3. Структуры и функции

Допустимые операции над структурами:

- копирование;
- присваивание;
- взятие адреса `&`;
- доступ к элементам.

Структуры **нельзя сравнивать** операторами `==` или `!=`. Инициализировать структуру можно списком констант; автоматическую структуру — также присваиванием.

### Способы передачи структур в функции

1. Передавать компоненты по отдельности.
2. Передавать всю структуру целиком.
3. Передавать указатель на структуру.

У каждого подхода есть плюсы и минусы.

### Пример: `makepoint`

```c
/* makepoint: формирует точку по компонентам x и y */
struct point makepoint(int x, int y)
{
    struct point temp;
    temp.x = x;
    temp.y = y;
    return temp;
}
```

Использование:

```c
struct rect screen;
struct point middle;
struct point makepoint(int, int);

screen.pt1 = makepoint(0, 0);
screen.pt2 = makepoint(XMAX, YMAX);
middle = makepoint((screen.pt1.x + screen.pt2.x) / 2,
                   (screen.pt1.y + screen.pt2.y) / 2);
```

### Пример: `addpoint`

```c
/* addpoint: сложение двух точек */
struct point addpoint(struct point p1, struct point p2)
{
    p1.x += p2.x;
    p1.y += p2.y;
    return p1;
}
```

Здесь оба аргумента и возвращаемое значение — структуры. Структурные параметры передаются **по значению**, как и любые другие.

### Пример: `ptinrect`

```c
/* ptinrect: возвращает 1, если p в r, и 0 в противном случае */
int ptinrect(struct point p, struct rect r)
{
    return p.x >= r.pt1.x && p.x < r.pt2.x &&
           p.y >= r.pt1.y && p.y < r.pt2.y;
}
```

Предполагается, что прямоугольник представлен в стандартном виде: координаты `pt1` меньше соответствующих координат `pt2`.

### Пример: `canonrect`

```c
#define min(a, b) ((a) < (b) ? (a) : (b))
#define max(a, b) ((a) > (b) ? (a) : (b))

/* canonrect: канонизация координат прямоугольника */
struct rect canonrect(struct rect r)
{
    struct rect temp;
    temp.pt1.x = min(r.pt1.x, r.pt2.x);
    temp.pt1.y = min(r.pt1.y, r.pt2.y);
    temp.pt2.x = max(r.pt1.x, r.pt2.x);
    temp.pt2.y = max(r.pt1.y, r.pt2.y);
    return temp;
}
```

### Указатели на структуры

```c
struct point *pp;
```

Если `pp` указывает на структуру `point`, то:

- `*pp` — сама структура;
- `(*pp).x` и `(*pp).y` — её элементы.

Пример:

```c
struct point origin, *pp;
pp = &origin;
printf("origin: (%d,%d)\n", (*pp).x, (*pp).y);
```

Скобки в `(*pp).x` обязательны, потому что приоритет оператора `.` выше, чем `*`. Выражение `*pp.x` было бы проинтерпретировано как `*(pp.x)`, что неверно.

### Оператор `->`

Для доступа к элементу через указатель используется короткая форма:

```c
p->элемент
```

Пример:

```c
printf("origin: (%d,%d)\n", pp->x, pp->y);
```

Операторы `.` и `->` выполняются слева направо. Если:

```c
struct rect r, *rp = &r;
```

то эквивалентны:

```c
r.pt1.x
rp->pt1.x
(r.pt1).x
(rp->pt1).x
```

### Приоритеты

Операторы `.` и `->` вместе с `()` и `[]` занимают самое высокое положение в иерархии приоритетов.

Пример:

```c
struct { int len; char *str; } *p;
```

- `++p->len` увеличивает `len`, а не указатель `p`: `++(p->len)`.
- `(++p)->len` сначала увеличивает `p`, затем берёт `len`.
- `(p++)->len` сначала берёт `len`, затем увеличивает `p`.
- `*p->str` — содержимое объекта, на который указывает `str`.
- `*p->str++` — увеличивает `str` после получения значения объекта.
- `(*p->str)++` — увеличивает значение объекта, на который указывает `str`.
- `*p++->str` — увеличивает `p` после получения того, на что указывает `str`.

## 4. Массивы структур

Пример: подсчёт вхождений ключевых слов в текст C-программы.

Вместо двух параллельных массивов:

```c
char *keyword[NKEYS];
int keycount[NKEYS];
```

удобнее использовать массив структур:

```c
struct key {
    char *word;
    int count;
} keytab[NKEYS];
```

Или:

```c
struct key {
    char *word;
    int count;
};
struct key keytab[NKEYS];
```

### Инициализация

```c
struct key {
    char *word;
    int count;
} keytab[] = {
    "auto", 0,
    "break", 0,
    "case", 0,
    "char", 0,
    "const", 0,
    "continue", 0,
    "default", 0,
    /* ... */
    "unsigned", 0,
    "void", 0,
    "volatile", 0,
    "while", 0
};
```

Число элементов массива вычисляется по количеству инициализаторов, если в квадратных скобках ничего не указано.

### Вычисление `NKEYS`

```c
#define NKEYS (sizeof keytab / sizeof(struct key))
```

или:

```c
#define NKEYS (sizeof keytab / sizeof keytab[0])
```

Второй вариант лучше: не нужно менять при изменении типа.

`sizeof` — унарный оператор времени компиляции. Он возвращает размер объекта или типа в байтах. Результат имеет тип `size_t`, определённый в `<stddef.h>`.

### Программа подсчёта ключевых слов

```c
#include <stdio.h>
#include <ctype.h>
#include <string.h>

#define MAXWORD 100

int getword(char *, int);
int binsearch(char *, struct key *, int);

/* подсчёт ключевых слов Си */
main()
{
    int n;
    char word[MAXWORD];

    while (getword(word, MAXWORD) != EOF)
        if (isalpha(word[0]))
            if ((n = binsearch(word, keytab, NKEYS)) >= 0)
                keytab[n].count++;

    for (n = 0; n < NKEYS; n++)
        if (keytab[n].count > 0)
            printf("%4d %s\n", keytab[n].count, keytab[n].word);

    return 0;
}

/* binsearch: найти слово в tab[0]...tab[n-1] */
int binsearch(char *word, struct key tab[], int n)
{
    int cond;
    int low, high, mid;

    low = 0;
    high = n - 1;
    while (low <= high) {
        mid = (low + high) / 2;
        if ((cond = strcmp(word, tab[mid].word)) < 0)
            high = mid - 1;
        else if (cond > 0)
            low = mid + 1;
        else
            return mid;
    }
    return -1;
}
```

### Функция `getword`

```c
/* getword: принимает следующее слово или символ из ввода */
int getword(char *word, int lim)
{
    int c, getch(void);
    void ungetch(int);
    char *w = word;

    while (isspace(c = getch()))
        ;
    if (c != EOF)
        *w++ = c;
    if (!isalpha(c)) {
        *w = '\0';
        return c;
    }
    for ( ; --lim > 0; w++)
        if (!isalnum(*w = getch())) {
            ungetch(*w);
            break;
        }
    *w = '\0';
    return word[0];
}
```

Функция использует `getch` и `ungetch` из главы 4. `isspace`, `isalpha`, `isalnum` описаны в `<ctype.h>`.

## 5. Указатели на структуры

Перепишем программу подсчёта ключевых слов, используя указатели вместо индексов.

```c
#include <stdio.h>
#include <ctype.h>
#include <string.h>

#define MAXWORD 100

int getword(char *, int);
struct key *binsearch(char *, struct key *, int);

/* подсчёт ключевых слов Си: версия с указателями */
main()
{
    char word[MAXWORD];
    struct key *p;

    while (getword(word, MAXWORD) != EOF)
        if (isalpha(word[0]))
            if ((p = binsearch(word, keytab, NKEYS)) != NULL)
                p->count++;

    for (p = keytab; p < keytab + NKEYS; p++)
        if (p->count > 0)
            printf("%4d %s\n", p->count, p->word);

    return 0;
}

/* binsearch: найти слово word в tab[0]...tab[n-1] */
struct key *binsearch(char *word, struct key *tab, int n)
{
    int cond;
    struct key *low = &tab[0];
    struct key *high = &tab[n];
    struct key *mid;

    while (low < high) {
        mid = low + (high - low) / 2;
        if ((cond = strcmp(word, mid->word)) < 0)
            high = mid;
        else if (cond > 0)
            low = mid + 1;
        else
            return mid;
    }
    return NULL;
}
```

Важные моменты:

- `binsearch` возвращает `struct key *` или `NULL`.
- Доступ к элементам `keytab` — через указатели.
- `low` и `high` инициализируются указателями на начало и на место сразу после конца массива.
- Нельзя писать `mid = (low + high) / 2`, потому что указатели нельзя складывать.
- Можно использовать `mid = low + (high - low) / 2`.
- Адрес `&tab[n]` находится за пределами массива, но по правилам языка его можно использовать в арифметике указателей. `&tab[-1]` недопустим.
- При `p++`, где `p` — указатель на структуру, `p` увеличивается на размер структуры.
- Размер структуры может быть больше суммы размеров её элементов из-за выравнивания. Например:

```c
struct { char c; int i; };
```

может занимать 8 байт, а не 5. `sizeof` вернёт правильное значение.

### Оформление возвращаемого типа

Если функция возвращает указатель на структуру:

```c
struct key *binsearch(char *word, struct key *tab, int n)
```

иногда пишут так:

```c
struct key *
binsearch(char *word, struct key *tab, int n)
```

Выбор — дело вкуса.

## 6. Структуры со ссылками на себя

Для подсчёта частоты любых слов входного потока удобно использовать **бинарное дерево**.

Узел дерева содержит:

- указатель на текст слова;
- счётчик числа вхождений;
- указатель на левый дочерний узел;
- указатель на правый дочерний узел.

```c
struct tnode {          /* узел дерева */
    char *word;         /* указатель на текст */
    int count;          /* число вхождений */
    struct tnode *left; /* левый сын */
    struct tnode *right;/* правый сын */
};
```

Структура не может включать саму себя, но может содержать указатель на себя. Это правильное рекурсивное определение.

Иногда нужны взаимоссылающиеся структуры:

```c
struct t {
    struct s *p; /* p указывает на s */
};

struct s {
    struct t *q; /* q указывает на t */
};
```

### Программа подсчёта частоты слов

```c
#include <stdio.h>
#include <ctype.h>
#include <string.h>

#define MAXWORD 100

struct tnode *addtree(struct tnode *, char *);
void treeprint(struct tnode *);
int getword(char *, int);

/* подсчёт частоты встречаемости слов */
main()
{
    struct tnode *root;
    char word[MAXWORD];

    root = NULL;
    while (getword(word, MAXWORD) != EOF)
        if (isalpha(word[0]))
            root = addtree(root, word);
    treeprint(root);
    return 0;
}
```

### Добавление узла

```c
struct tnode *talloc(void);
char *strdup(char *);

/* addtree: добавляет узел со словом w в p или ниже него */
struct tnode *addtree(struct tnode *p, char *w)
{
    int cond;

    if (p == NULL) {          /* слово встречается впервые */
        p = talloc();         /* создаётся новый узел */
        p->word = strdup(w);
        p->count = 1;
        p->left = p->right = NULL;
    } else if ((cond = strcmp(w, p->word)) == 0)
        p->count++;           /* это слово уже встречалось */
    else if (cond < 0)        /* меньше корня левого поддерева */
        p->left = addtree(p->left, w);
    else                      /* больше корня правого поддерева */
        p->right = addtree(p->right, w);
    return p;
}
```

### Печать дерева

```c
/* treeprint: упорядоченная печать дерева p */
void treeprint(struct tnode *p)
{
    if (p != NULL) {
        treeprint(p->left);
        printf("%4d %s\n", p->count, p->word);
        treeprint(p->right);
    }
}
```

Если дерево несбалансировано, время работы может сильно возрасти. Худший случай — слова уже упорядочены; тогда затраты такие же, как при линейном поиске.

### Выделение памяти

```c
#include <stdlib.h>

/* talloc: создаёт tnode */
struct tnode *talloc(void)
{
    return (struct tnode *) malloc(sizeof(struct tnode));
}

char *strdup(char *s) /* делает дубликат s */
{
    char *p;
    p = (char *) malloc(strlen(s) + 1); /* +1 для '\0' */
    if (p != NULL)
        strcpy(p, s);
    return p;
}
```

`malloc` возвращает `NULL`, если свободного пространства нет. `strdup` возвращает это же значение, оставляя обработку ошибки вызывающей программе.

> **Примечание:** `strdup` не входит в стандарт C (до C23) и является POSIX-функцией. В K&R она реализована вручную.

### Упражнения

- **6.2.** Программа, читающая текст C-программы и печатающая в алфавитном порядке группы имён переменных, у которых совпадают первые 6 символов. Число 6 — параметр командной строки.
- **6.3.** Программа печати таблицы перекрёстных ссылок: все слова документа и номера строк, где они встретились. Игнорировать шумовые слова.

## 7. Просмотр таблиц

Рассматривается ядро пакета для работы с таблицей имён, типичное для макропроцессора или компилятора.

Основные функции:

- `install(s, t)` — записывает имя `s` и замещающий текст `t` в таблицу;
- `lookup(s)` — ищет `s` в таблице и возвращает указатель на найденное место или `NULL`.

Алгоритм основан на **хэш-поиске**.

### Структура элемента таблицы

```c
struct nlist {          /* элемент таблицы */
    struct nlist *next; /* указатель на следующий элемент */
    char *name;         /* определённое имя */
    char *defn;         /* замещающий текст */
};
```

### Массив указателей

```c
#define HASHSIZE 101
static struct nlist *hashtab[HASHSIZE]; /* таблица указателей */
```

### Хэш-функция

```c
/* hash: получает хэш-код для строки s */
unsigned hash(char *s)
{
    unsigned hashval;

    for (hashval = 0; *s != '\0'; s++)
        hashval = *s + 31 * hashval;
    return hashval % HASHSIZE;
}
```

Беззнаковая арифметика гарантирует неотрицательность хэш-кода.

### Поиск

```c
/* lookup: ищет s */
struct nlist *lookup(char *s)
{
    struct nlist *np;

    for (np = hashtab[hash(s)]; np != NULL; np = np->next)
        if (strcmp(s, np->name) == 0)
            return np; /* нашли */
    return NULL;       /* не нашли */
}
```

### Вставка

```c
struct nlist *lookup(char *);
char *strdup(char *);

/* install: заносит имя и текст (name, defn) в таблицу */
struct nlist *install(char *name, char *defn)
{
    struct nlist *np;
    unsigned hashval;

    if ((np = lookup(name)) == NULL) { /* не найден */
        np = (struct nlist *) malloc(sizeof(*np));
        if (np == NULL || (np->name = strdup(name)) == NULL)
            return NULL;
        hashval = hash(name);
        np->next = hashtab[hashval];
        hashtab[hashval] = np;
    } else { /* уже имеется */
        free((void *) np->defn); /* освобождаем прежний defn */
    }
    if ((np->defn = strdup(defn)) == NULL)
        return NULL;
    return np;
}
```

## 8. Средство typedef

`typedef` позволяет давать типам данных новые имена.

```c
typedef int Length;
Length len, maxlen;
Length *lengths[];
```

```c
typedef char *String;
String p, lineptr[MAXLINES], alloc(int);
int strcmp(String, String);
p = (String) malloc(100);
```

Синтаксически `typedef` напоминает класс памяти (`extern`, `static`). Имена типов часто пишут с заглавной буквы.

### Пример со структурами

```c
typedef struct tnode *Treeptr;

typedef struct tnode {   /* узел дерева */
    char *word;          /* указатель на текст */
    int count;           /* число вхождений */
    Treeptr left;        /* левый сын */
    Treeptr right;       /* правый сын */
} Treenode;
```

Теперь `talloc` можно записать так:

```c
Treeptr talloc(void)
{
    return (Treeptr) malloc(sizeof(Treenode));
}
```

### Указатель на функцию

```c
typedef int (*PFI)(char *, char *);
PFI strcmp, numcmp;
```

`typedef` не создаёт новый тип, а лишь даёт новое имя существующему. Он аналогичен `#define`, но обрабатывается компилятором и может справляться с более сложными подстановками.

Две важные причины использовать `typedef`:

1. **Переносимость.** Если машинно-зависимые типы объявлены через `typedef`, при переносе программы изменения вносятся только в определения `typedef`.
2. **Читаемость.** Сложные типы становятся понятнее.

## 9. Объединения

**Объединение** — переменная, которая может содержать в разные моменты времени объекты различных типов и размеров. Компилятор выполняет все требования по размерам и выравниванию. Аналог — вариантные записи в Паскале.

```c
union u_tag {
    int ival;
    float fval;
    char *sval;
} u;
```

Переменная `u` будет достаточно большой, чтобы поместить любой из трёх типов. Точный размер зависит от реализации.

Доступ к элементам:

```c
имя-объединения.элемент
указатель-на-объединение->элемент
```

Пример с отслеживанием текущего типа:

```c
if (utype == INT)
    printf("%d\n", u.ival);
else if (utype == FLOAT)
    printf("%f\n", u.fval);
else if (utype == STRING)
    printf("%s\n", u.sval);
else
    printf("неверный тип %d в utype\n", utype);
```

Объединения могут входить в структуры и массивы, и наоборот.

```c
struct {
    char *name;
    int flags;
    int utype;
    union {
        int ival;
        float fval;
        char *sval;
    } u;
} symtab[NSYM];
```

Доступ:

```c
symtab[i].u.ival
*symtab[i].u.sval
symtab[i].u.sval[0]
```

Фактически объединение — это структура, все элементы которой имеют нулевое смещение относительно базового адреса, а размер достаточен для самого большого элемента.

К объединениям применимы те же операции, что и к структурам: присваивание, копирование, взятие адреса, доступ к элементам.

Инициализировать объединение можно только значением, имеющим тип его первого элемента.

## 10. Битовые поля

При дефиците памяти несколько объектов можно упаковать в одно слово. Один из способов — использовать **битовые поля**.

### Маски

```c
#define KEYWORD 01   /* ключевое слово */
#define EXTERNAL 02  /* внешний */
#define STATIC 04    /* статический */
```

или:

```c
enum { KEYWORD = 01, EXTERNAL = 02, STATIC = 04 };
```

Числа должны быть степенями двойки.

```c
flags |= EXTERNAL | STATIC;          /* установить биты */
flags &= ~(EXTERNAL | STATIC);       /* обнулить биты */
if ((flags & (EXTERNAL | STATIC)) == 0) ...
```

### Битовые поля

```c
struct {
    unsigned int is_keyword : 1;
    unsigned int is_extern  : 1;
    unsigned int is_static  : 1;
} flags;
```

Число после двоеточия задаёт ширину поля. Поля объявлены как `unsigned int`, чтобы восприниматься как беззнаковые.

Доступ:

```c
flags.is_keyword
flags.is_extern
flags.is_static
```

Примеры:

```c
flags.is_extern = flags.is_static = 1;   /* установить */
flags.is_extern = flags.is_static = 0;   /* обнулить */
if (flags.is_extern == 0 && flags.is_static == 0) ...
```

### Особенности

- Поля могут не иметь имени; безымянное поле задаётся только двоеточием и шириной.
- Ширина `0` используется для выхода на границу следующего слова.
- Расположение полей слева направо или справа налево зависит от реализации.
- Программы, зависящие от порядка расположения полей, непереносимы.
- Поля можно определять только с типом `int`; для переносимости нужно явно указывать `signed` или `unsigned`.
- Поля не могут быть массивами.
- У полей нет адресов, поэтому оператор `&` к ним неприменим.

## 11. Дополнительно важное

1. **ANSI C** добавил в структуры присваивание, копирование, передачу в функции и возврат из функций.
2. **Структуры нельзя сравнивать** через `==` или `!=`. Нужно сравнивать поэлементно или через `memcmp` (с осторожностью из-за выравнивания).
3. **Выравнивание.** Размер структуры может быть больше суммы размеров элементов. `sizeof` возвращает правильный размер.
4. **`malloc`** возвращает `void *`, поэтому в C явное приведение не обязательно, но в K&R показано. Заголовок — `<stdlib.h>`.
5. **`strdup`** — не стандартная функция C (до C23), а POSIX. В учебнике K&R она реализуется вручную.
6. **`typedef` vs `#define`.** `typedef` обрабатывается компилятором и корректно работает со сложными типами; `#define` — препроцессором и может приводить к неожиданностям.
7. **Битовые поля** экономичны, но непереносимы при зависимости от порядка битов.
8. **Объединения** позволяют хранить разные типы в одной области памяти, но ответственность за правильную интерпретацию лежит на программисте.
9. **Деревья.** Бинарное дерево эффективно для динамического набора слов, но может стать несбалансированным. В худшем случае скорость падает до линейной.
10. **Хэш-таблицы.** Простая хэш-функция и цепочки блоков — типичный приём для таблиц имён в компиляторах и макропроцессорах.
