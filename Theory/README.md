# Глава 1. Обзор языка C

## 1. Базовая структура программы
*   **Функции и переменные**: Программа на C состоит из функций и переменных. Функции содержат инструкции (вычисления), переменные хранят значения.
*   **`main`**: Особая функция. Любая программа начинается с первой инструкции `main`.
*   **Директивы препроцессора**: `#include <stdio.h>` подключает стандартную библиотеку ввода-вывода (I/O).
*   **Фигурные скобки `{}`**: Ограничивают тело функции или блок инструкций.
*   **Точка с запятой `;`**: Завершает любую инструкцию (statement).
*   **Комментарии**: `/* ... */` игнорируются компилятором.

## 2. Переменные и типы данных
*   **Объявление**: Все переменные должны быть объявлены до использования. Обычно в начале функции.
*   **Базовые типы**:
    *   `int` — целые числа (обычно 16 или 32 бита).
    *   `float` — числа с плавающей точкой (дробные).
    *   `char` — один байт (символ).
    *   `short`, `long`, `double` — вариации для увеличения диапазона/точности.
*   **Именованные константы (`#define`)**: Позволяют избежать «магических чисел» в коде.
    *   Синтаксис: `#define ИМЯ значение` (без `;` в конце!).
    *   По соглашению пишутся заглавными буквами (`LOWER`, `UPPER`).

## 3. Арифметика и операторы
*   **Целочисленное деление**: Важнейшая особенность! `5/9` всегда равно `0`, так как дробная часть отбрасывается. Для получения дробного результата нужно использовать `5.0/9.0`.
*   **Приоритет операторов**: Умножение/деление выше сложения/вычитания. Скобки меняют приоритет.
*   **Инкремент/Декремент**: `++nc` (увеличить на 1) и `--nc` (уменьшить на 1). Бывают префиксными (`++nc`) и постфиксными (`nc++`). В выражениях они имеют разный смысл (в главе 1 используется префиксная форма для счетчиков).
*   **Операторы сравнения**: `!=` (не равно), `==` (равно). **Важно:** `=` — это присваивание, `==` — сравнение. Их путаница — классическая ошибка новичков.

## 4. Управляющие конструкции
*   **`while (условие)`**: Проверяет условие *перед* выполнением тела. Если условие ложно изначально, тело не выполнится ни разу.
*   **`for (инициализация; условие; шаг)`**: Удобен, когда инициализация и шаг логически связаны. Эквивалентен `while`, но компактнее.
*   **`if (условие) ... else if (условие) ... else ...`**: Многопутевое ветвление.
*   **Логические операторы**: `&&` (И), `||` (ИЛИ). Обладают **коротким замыканием** (вычисления прекращаются, как только результат ясен). Приоритет `&&` выше, чем `||`.
*   **Пустая инструкция**: `;` (используется, когда тело цикла не нужно, например, в `for` для подсчета).

## 5. Ввод и вывод (I/O)
### Форматированный вывод (`printf`)
*   `%d` — целое десятичное.
*   `%f` — число с плавающей точкой.
*   `%s` — строка.
*   `%c` — символ.
*   `%o`, `%x` — восьмеричное, шестнадцатеричное.
*   **Ширина и точность**: `%3d` (поле из 3 позиций), `%6.1f` (поле 6, 1 знак после запятой).
*   **Эскейп-последовательности**: `\n` (новая строка), `\t` (табуляция), `\b` (забой), `\\` (обратный слэш), `\"` (кавычка).

### Посимвольный ввод/вывод (`getchar` / `putchar`)
*   **Модель потока**: Текст — это поток символов.
*   **`c = getchar()`**: Читает следующий символ из потока.
*   **`putchar(c)`**: Печатает символ.
*   **`EOF` (End Of File)**: Специальное значение, возвращаемое `getchar()`, когда поток исчерпан.
*   **Почему `int c`, а не `char c`?** `char` слишком мал, чтобы вместить все возможные символы *плюс* значение `EOF`. Поэтому используется `int`.
*   **Идиома C**: `while ((c = getchar()) != EOF)`
    *   Присваивание внутри условия. Скобки обязательны, так как приоритет `!=` выше, чем `=`. Без скобок `c` получило бы 0 или 1.

## 6. Массивы и строки
*   **Массивы**: `int ndigit[10];` — индексация начинается с **0**.
*   **Символы как целые**: `char` — это просто маленькое целое. `c - '0'` дает числовое значение цифры (например, `'5' - '0' = 5`).
*   **Строки**: В C нет типа «строка». Это массив символов, **обязательно заканчивающийся нулевым символом `\0`**.
*   **`'\0'`**: Маркер конца строки. Используется функциями `printf("%s")`, `copy` и другими.
*   **Разница**: `'x'` — это один символ (целое число). `"x"` — это строка (массив из `'x'` и `'\0'`).

## 7. Функции
*   **Определение**: `тип_результата имя(параметры) { тело }`.
*   **Прототип**: `int power(int m, int n);` — объявление функции до ее использования. Позволяет компилятору проверять типы аргументов.
*   **Параметры vs Аргументы**:
    *   *Параметры* — переменные в определении функции.
    *   *Аргументы* — значения, передаваемые при вызове.
*   **`return`**: Возвращает значение (или просто завершает функцию, если без выражения).
*   **`void`**: Если функция ничего не возвращает, используется тип `void` (например, `void copy(...)`).
*   **Вызов по значению (Call by Value)**: **Ключевая концепция C.** В функцию передаются *копии* значений аргументов. Изменение параметров внутри функции не влияет на оригинальные переменные в вызывающей функции. (Для изменения оригинала нужно передавать указатель, но это тема следующих глав).

## 8. Область видимости (Scope) и классы памяти
*   **Локальные (автоматические) переменные**:
    *   Объявлены внутри функции.
    *   Создаются при входе в функцию, уничтожаются при выходе.
    *   Не сохраняют значения между вызовами (содержат «мусор»).
    *   Доступны только внутри своей функции.
*   **Внешние (глобальные) переменные**:
    *   Определены вне функций.
    *   Доступны любой функции (если объявлены с `extern` или определены выше по файлу).
    *   Существуют всё время работы программы.
    *   **Осторожно**: Чрезмерное использование внешних переменных ведет к запутанному коду и трудностям при отладке. Лучше передавать данные через аргументы.
*   **`extern`**: Ключевое слово для *объявления* внешней переменной (сообщает компилятору, что она где-то определена, память под нее выделять не нужно).
*   **Заголовочные файлы (`.h`)**: Собирают прототипы функций и объявления внешних переменных для использования в нескольких `.c` файлах.

## 9. Практические примеры из главы (для запоминания)
1.  **Hello, world**: Базовая структура, `printf`.
2.  **Таблица температур**: `while`/`for`, `int` vs `float`, целочисленное деление, форматированный вывод.
3.  **Копирование файла**: `getchar`/`putchar`, `EOF`, идиома `while ((c = getchar()) != EOF)`.
4.  **Подсчет символов/строк/слов**: `long`, `++`, `if-else`, `||`/`&&`, `#define` для состояний (`IN`/`OUT`).
5.  **Гистограмма цифр**: Массивы, `c - '0'`, `switch` (в следующих главах).
6.  **Поиск самой длинной строки**: Работа со строками, `getline`, `copy`, `\0`, `void`, передача массивов в функции.

# Глава 2. Типы, операторы и выражения

## 1. Имена, типы и квалификаторы (Фундамент данных)

### 1.1. Правила именования
*   Первый символ — буква. Далее — буквы, цифры и `_`.
*   Регистрозависимы (`x` и `X` — разные).
*   **Значимость:** Для внутренних имен значимы первые 31 символ. Для внешних (функции, глобальные переменные) — только первые 6 символов (и регистр может не учитываться). Это ограничение линковщиков.
*   Не начинайте с `_` — это зарезервировано для библиотек.

### 1.2. Базовые типы и их размеры
*   `char` — 1 байт. Может быть `signed` или `unsigned` (зависит от машины). Всегда положителен для печатаемых символов.
*   `int` — естественный размер для машины (обычно 16 или 32 бита).
*   `short` >= 16 бит, `long` >= 32 бита. `short <= int <= long`.
*   `float`, `double`, `long double` — точность зависит от реализации.
*   **Квалификаторы:** `short`, `long`, `signed`, `unsigned`. `signed`/`unsigned` применяются к целым. `unsigned` работает по модулю 2^n.

### 1.3. `const` (Константность)
*   `const double e = 2.718;` — запрет на изменение.
*   `const char msg[] = "..."` — массив нельзя менять.
*   `int strlen(const char[]);` — функция обещает не менять массив.

---

## 2. Константы (Как записывать данные)

*   **Целые:** `1234` (int), `123456789L` (long), `123U` (unsigned), `0x1F` (hex), `037` (octal). Суффиксы: `U`, `L`, `UL`.
*   **Плавающие:** `123.4`, `1e-2` (double по умолчанию), `123.4f` (float), `1e-2L` (long double).
*   **Символьные:** `'A'` — это целое число (код ASCII, например, 65). Эскейп-последовательности: `\n`, `\t`, `\0`, `\ooo` (восьмеричный код), `\xhh` (шестнадцатеричный код).
*   **Строковые:** `"hello"` — массив символов, **всегда** заканчивающийся `\0`.
    *   `strlen(s)` считает символы до `\0` (не включая его).
    *   Конкатенация: `"hello" " world"` -> `"hello world"`.
*   **Перечисления (`enum`):** `enum boolean { NO, YES };` — NO = 0, YES = 1. Удобны для читаемости.

## 3. Операторы (Действия над данными)

### 3.1. Арифметические (`+ - * / %`)
*   **Целочисленное деление:** `5/9 == 0`. Дробная часть отбрасывается.
*   **Остаток `%`:** Работает только с целыми. `x % y` — остаток от деления.
*   **Приоритет:** `* / %` выше, чем `+ -`. Унарные `+ -` выше бинарных.

### 3.2. Отношения и логика (`> >= < <= == != && || !`)
*   Результат — всегда `1` (истина) или `0` (ложь).
*   **Короткое замыкание (Short-circuit):** Вычисление `&&` и `||` прекращается, как только результат ясен.
    *   **Применение в I/O (из Главы 1):**
        ```c
        for (i = 0; i < lim-1 && (c = getchar()) != EOF && c != '\n'; ++i)
        ```
        Здесь порядок критичен: сначала проверяем место в буфере, потом читаем символ, потом проверяем на конец файла/строки. Если места нет, `getchar()` даже не вызовется.
*   **Приоритет:** `&&` выше, чем `||`. Оба ниже, чем операторы сравнения.

### 3.3. Побитовые операторы (`& | ^ << >> ~`)
*   **`&` (И):** Маскирование (обнуление) битов. `n = n & 0177;` (оставить младшие 7 бит).
*   **`|` (ИЛИ):** Установка битов. `x = x | SET_ON;`
*   **`^` (Исключающее ИЛИ):** Инверсия битов по маске.
*   **`<<` / `>>`:** Сдвиг. `x << 2` — умножение на 4. `x >> 2` — деление на 4.
    *   **Ловушка:** Сдвиг вправо для `signed` чисел зависит от машины (арифметический сдвиг с сохранением знака или логический с нулями). Для переносимости используйте `unsigned`.
*   **`~`:** Побитовое отрицание. `~0` — все единицы.
*   **Практика (Функция `getbits`):**
    ```c
    unsigned getbits(unsigned x, int p, int n) {
        return (x >> (p+1-n)) & ~(~0 << n);
    }
    ```
    *   `x >> (p+1-n)` — сдвигает нужное поле к правому краю.
    *   `~(~0 << n)` — создает маску из `n` единиц справа. `~0` — все единицы, сдвиг влево на `n` дает нули справа, инверсия возвращает единицы.

### 3.4. Инкремент и декремент (`++`, `--`)
*   **Префиксный `++n`:** Сначала увеличивает, потом возвращает.
*   **Постфиксный `n++`:** Сначала возвращает, потом увеличивает.
*   **Практика:** `s[j++] = s[i];` — классическая идиома копирования с одновременным сдвигом индекса.
*   **Ограничение:** Применяются только к переменным. `(i+j)++` — ошибка.

### 3.5. Присваивание (`op=`)
*   `i += 2` эквивалентно `i = i + 2`.
*   `x *= y + 1` эквивалентно `x = x * (y + 1)`. Скобки важны!
*   Левая часть вычисляется только один раз (важно для сложных выражений).

### 3.6. Условное выражение (`? :`)
*   `z = (a > b) ? a : b;` — тернарный оператор.
*   Вычисляется только одна из ветвей `?` или `:`.
*   Тип результата определяется по правилам преобразования типов (например, `float` и `int` дадут `float`).

---

## 4. Преобразования типов (Правила игры)

### 4.1. Неявные преобразования (Автоматические)
*   **Повышение (Promotion):** Если операнды разных типов, «младший» приводится к «старшему».
    *   `char`, `short` -> `int` (в арифметических выражениях).
    *   `int` -> `float` -> `double` -> `long double`.
*   **Правила:**
    1. Если есть `long double` -> все к `long double`.
    2. Иначе если есть `double` -> все к `double`.
    3. Иначе если есть `float` -> все к `float`.
    4. Иначе `char`/`short` -> `int`.
    5. Иначе если есть `long` -> все к `long`.
*   **Ловушка `char`:** `char` может быть знаковым или беззнаковым. При преобразовании в `int` может произойти расширение знака (отрицательное число) или добавление нулей. Для не-символьных данных используйте `signed char` или `unsigned char`.

### 4.2. Явные преобразования (Приведение, Cast)
*   `(double) n` — приводит `n` к `double`, но не меняет саму переменную `n`.
*   **Пример (Функция `atoi`):**
    ```c
    int atoi(char s[]) {
        int i, n = 0;
        for (i = 0; s[i] >= '0' && s[i] <= '9'; ++i)
            n = 10 * n + (s[i] - '0');
        return n;
    }
    ```
    Здесь `s[i] - '0'` дает числовое значение цифры (например, `'5' - '0' = 5`).

### 4.3. Ловушка `unsigned` и `signed`
*   Сравнение знаковых и беззнаковых чисел может дать неожиданный результат.
*   Пример (при 16-битном `int` и 32-битном `long`):
    *   `-1L < 1U` -> Истина (1U повышается до `signed long`).
    *   `-1L > 1UL` -> Истина (`-1L` повышается до `unsigned long` и становится огромным положительным числом).

---

## 5. Приоритет и очередность вычислений (Самое опасное)

### 5.1. Таблица приоритетов (От высшего к низшему)
1.  `()` `[]` `->` `.` (слева направо)
2.  `!` `~` `++` `--` `+` `-` `*` `&` `(type)` `sizeof` (справа налево)
3.  `*` `/` `%` (слева направо)
4.  `+` `-` (слева направо)
5.  `<<` `>>` (слева направо)
6.  `<` `<=` `>` `>=` (слева направо)
7.  `==` `!=` (слева направо)
8.  `&` (слева направо)
9.  `^` (слева направо)
10. `|` (слева направо)
11. `&&` (слева направо)
12. `||` (слева направо)
13. `? :` (справа налево)
14. `=` `+=` `-=` `*=` `/=` `%=` `&=` `^=` `|=` `<<=` `>>=` (справа налево)
15. `,` (слева направо)

*   **Важно:** Побитовые операторы `&`, `^`, `|` имеют **более низкий** приоритет, чем `==` и `!=`. Поэтому `if ((x & MASK) == 0)` требует скобок.

### 5.2. Порядок вычислений (Order of Evaluation)
*   C **не** гарантирует порядок вычисления операндов (кроме `&&`, `||`, `?:`, `,`).
*   **Пример опасности:**
    ```c
    x = f() + g(); // f() может быть вызвана до g(), а может и после.
    ```
*   **Побочные эффекты (Side Effects):**
    ```c
    printf("%d %d\n", ++n, power(2, n)); // НЕПРАВИЛЬНО! Зависит от компилятора.
    a[i] = i++; // НЕПРАВИЛЬНО! Неопределенное поведение.
    ```
*   **Мораль:** Не пишите код, который зависит от порядка вычислений. Если сомневаетесь — используйте временные переменные.

# Глава 3. Управление 

## 1. Инструкции и блоки (Фундамент синтаксиса)
*   **Инструкция (Statement):** Любое выражение, заканчивающееся `;`. Точка с запятой — это **терминатор**, а не разделитель (в отличие от Паскаля). Пустая инструкция `;` — это тоже инструкция.
*   **Блок (Block):** `{ ... }`. Объединяет объявления и инструкции в одну составную инструкцию. Синтаксически блок эквивалентен одной инструкции. После закрывающей `}` точка с запятой **не ставится**.
*   **Зачем нужны блоки?** Для группировки нескольких действий там, где синтаксис требует одну инструкцию (например, тело `if`, `while`, `for`).

## 2. Ветвление: if-else и else-if (Принятие решений)

### 2.1. `if-else`
*   **Синтаксис:** `if (выражение) инструкция1 else инструкция2`
*   **Механика:** Вычисляется выражение. Если оно **не ноль** (истина) -> выполняется `инструкция1`. Если **ноль** (ложь) и есть `else` -> выполняется `инструкция2`.
*   **Сокращенная запись:** `if (x)` эквивалентно `if (x != 0)`.

### 2.2. Ловушка «Висячего else» (Dangling Else)
*   **Проблема:** `else` всегда связывается с **ближайшим** `if`, у которого нет своего `else`.
    ```c
    if (n > 0)
        if (a > b)
            z = a;
    else // Этот else относится к if (a > b), а не к if (n > 0)!
        z = b;
    ```
*   **Решение:** Всегда используйте фигурные скобки `{}` для вложенных `if`, если есть малейшие сомнения. Это избавляет от неоднозначности и облегчает чтение.

### 2.3. Конструкция `else-if` (Многопутевое ветвление)
*   **Синтаксис:**
    ```c
    if (условие1) инструкция1;
    else if (условие2) инструкция2;
    else if (условие3) инструкция3;
    else инструкция_по_умолчанию;
    ```
*   **Механика:** Проверки идут сверху вниз. Как только условие истинно, выполняется соответствующая инструкция, и вся конструкция завершается.
*   **Пример (Бинарный поиск, `binsearch`):** Классический пример `else-if`. Сравниваем `x` с серединой массива. Если меньше — ищем в левой половине, если больше — в правой, если равно — возвращаем индекс. Логарифмическая сложность O(log n).

## 3. Множественный выбор: `switch`

*   **Назначение:** Выбор одной из многих ветвей на основе **целочисленного** выражения.
*   **Синтаксис:**
    ```c
    switch (выражение) {
        case конст1: инструкции; break;
        case конст2: инструкции; break;
        default: инструкции; break;
    }
    ```
*   **Ограничения:**
    *   `выражение` должно быть целочисленного типа (`int`, `char`, `enum`).
    *   `конст` должны быть **целочисленными константами** или константными выражениями. Переменные использовать нельзя.
    *   Все константы должны быть уникальны.
*   **Механика «Провала» (Fall-through):** Если не поставить `break`, выполнение «провалится» в следующую ветку `case`.
    *   **Полезное применение:** Группировка нескольких случаев.
        ```c
        case '0': case '1': case '2': // Все эти случаи делают одно и то же
            ndigit[c - '0']++;
            break;
        ```
    *   **Опасность:** Забытый `break` — это классическая ошибка, которая приводит к трудноуловимым багам. **Правило:** Всегда ставьте `break` в конце каждой ветки, кроме случаев намеренной группировки.
*   **`default`:** Выполняется, если ни одна из констант не совпала. Можно располагать в любом месте, но обычно ставят в конце.

## 4. Циклы: while, for, do-while

### 4.1. `while` и `for` (Циклы с предусловием)
*   **`while (выражение) инструкция`**: Проверка условия перед каждой итерацией. Может не выполниться ни разу.
*   **`for (выр1; выр2; выр3) инструкция`**:
    *   **Эквивалентен:** `выр1; while (выр2) { инструкция; выр3; }`
    *   **Механика:** `выр1` (инициализация) выполняется один раз. `выр2` (условие) проверяется перед каждой итерацией. `выр3` (шаг) выполняется после каждой итерации.
    *   **Любое из трех выражений может отсутствовать.** `for (;;)` — бесконечный цикл. Точки с запятой обязательны.
*   **Выбор между `while` и `for`:**
    *   `for` — когда есть простая инициализация и шаг (арифметическая прогрессия).
    *   `while` — когда инициализации/шага нет, или условие сложное (например, `while ((c = getchar()) == ' ')`).

### 4.2. Оператор «запятая» (`,`) в циклах
*   **Механика:** Выражения, разделенные запятой, вычисляются **слева направо**. Результат — значение **правого** выражения.
*   **Применение:** Позволяет вести два и более индекса параллельно в заголовке `for`.
    ```c
    for (i = 0, j = strlen(s)-1; i < j; i++, j--) { ... }
    ```
*   **Важно:** Запятые в аргументах функций и объявлениях переменных — это **не** оператор запятая.

### 4.3. `do-while` (Цикл с постусловием)
*   **Синтаксис:** `do инструкция while (выражение);`
*   **Механика:** Тело выполняется **хотя бы один раз**, затем проверяется условие. Если истина — повтор.
*   **Когда использовать:** Когда тело цикла должно выполниться минимум один раз, даже если условие изначально ложно.
*   **Пример (`itoa`):** Преобразование числа в строку. Даже если `n = 0`, нужно сгенерировать символ `'0'`.
    ```c
    do {
        s[i++] = n % 10 + '0'; // Генерируем цифру
    } while ((n /= 10) > 0);    // Отбрасываем её
    ```
    *Ловушка `itoa`*: Проблема с `-(2^n-1)` (самое большое по модулю отрицательное число). `n = -n` вызывает переполнение. Решается через `unsigned`.

## 5. Инструкции break, continue, goto

### 5.1. `break`
*   **Действие:** Немедленный выход из **самого внутреннего** цикла (`for`, `while`, `do-while`) или `switch`.
*   **Применение:** Выход из цикла по дополнительному условию, которое сложно проверить в заголовке.
*   **Пример (`trim`):** Удаление завершающих пробелов. Идем с конца строки, пока не встретим непробельный символ. Как только нашли — `break`.

### 5.2. `continue`
*   **Действие:** Прерывает текущую итерацию и переходит к **следующей**.
    *   Для `while`/`do-while`: немедленный переход к проверке условия.
    *   Для `for`: переход к шагу (`выр3`), затем к проверке условия.
*   **Применение:** Пропуск части тела цикла при определенных условиях (например, пропуск отрицательных элементов массива).
*   **Важно:** Не работает для `switch` (вызовет переход к следующей итерации объемлющего цикла).

### 5.3. `goto` и метки
*   **Синтаксис:** `goto метка;` ... `метка: инструкция;`
*   **Отношение:** Порицается, так как ведет к «спагетти-коду».
*   **Единственное оправданное применение:** Выход из **глубоко вложенных** циклов, когда `break` не справляется (выходит только из самого внутреннего).
    ```c
    for (...) 
        for (...) {
            if (disaster) goto error;
        }
    error:
        // обработка ошибки
    ```

# Глава 4. Функции и структура программы 

## 1. Архитектура программы: Раздельная компиляция и Заголовочные файлы

Программа на C — это набор внешних объектов (функций и переменных). Их можно компилировать по отдельности и связывать вместе.

### 1.1. Раздельная компиляция
*   Исходный код можно разбить на несколько файлов (`.c`).
*   Компиляция: `cc main.c getline.c strindex.c` создает объектные файлы (`main.o`, `getline.o`, `strindex.o`) и линкует их в исполняемый файл (`a.out`).
*   Если изменился только один файл, перекомпилируется только он, а остальные берутся из `.o`. Это **ключевое преимущество** для больших проектов.
*   **Правило:** Ни одна функция не может быть разрезана между файлами.

### 1.2. Заголовочные файлы (Header Files, `.h`)
*   **Проблема:** Если функция определена в одном файле, а используется в другом, компилятор должен знать её прототип (тип возврата и аргументы).
*   **Решение:** Создать `calc.h` и включать его через `#include "calc.h"`.
*   **Правило:** В заголовочном файле должны быть **только объявления** (прототипы функций, `extern` переменные), но **не определения** (тела функций, выделение памяти).
*   **Стандартные заголовки:** `<stdio.h>` — для I/O, `<ctype.h>` — для работы с символами (`isdigit`, `isspace`), `<stdlib.h>` — для `atof`, `atoi`.

### 1.3. Определение vs Объявление (Definition vs Declaration)
*   **Определение:** Создает объект, выделяет память. `int sp; double val[MAXVAL];` (вне функций).
*   **Объявление:** Сообщает компилятору свойства объекта, память не выделяет. `extern int sp; extern double val[];`.
*   **Правило одного определения:** На всю программу (все файлы) для каждой внешней переменной должно быть **ровно одно** определение. Остальные файлы используют `extern`.

## 2. Области видимости и Классы памяти (Storage Classes)

### 2.1. Внешние переменные (External Variables)
*   Доступны любой функции, если объявлены (`extern`).
*   Используются для связи между функциями без длинных списков аргументов.
*   **Опасность:** Чрезмерное использование ведет к «спагетти-коду» и трудностям отладки. Лучше передавать данные через аргументы.

### 2.2. Статические переменные (`static`)
*   **Для глобальных переменных и функций:** Ограничивает область видимости **пределами одного файла**. Скрывает имена от линковщика.
    *   *Применение:* Переменные `buf`, `bufp`, `sp`, `val` в калькуляторе. Функции `push` и `pop` видят их, а `main` — нет.
*   **Для локальных переменных:** Переменная не создается и не уничтожается при входе/выходе из функции. Она существует **постоянно**, сохраняя значение между вызовами.
    *   *Применение:* Счетчики, буферы, кэши внутри функции.

### 2.3. Регистровые переменные (`register`)
*   Подсказка компилятору: «Эта переменная будет использоваться интенсивно, помести её в регистр процессора».
*   Компилятор может проигнорировать.
*   **Ограничение:** К регистровой переменной **нельзя применить оператор `&`** (взять адрес).
*   Применяется только к автоматическим переменным и параметрам функций.

### 2.4. Блочная структура (Block Scope)
*   Переменные можно объявлять внутри любого блока `{}`.
*   Они «затеняют» (shadow) переменные с тем же именем во внешних блоках.
*   *Пример:* `if (n > 0) { int i; for (i = 0; ...) }`. Переменная `i` существует только внутри `if`.

### 2.5. Инициализация (Initialization Rules)
*   **Внешние и статические:** Инициализируются **нулями** по умолчанию. Инициализация происходит **один раз** до начала программы.
*   **Автоматические и регистровые:** Содержат **«мусор»** по умолчанию. Инициализируются **каждый раз** при входе в функцию/блок.
*   **Массивы:** `int days[] = {31, 28, ...};`. Если размер не указан, вычисляется по количеству инициализаторов.
*   **Строки:** `char pattern[] = "ould";` — эквивалентно `{'o','u','l','d','\0'}`.

## 3. Рекурсия (Recursion)

*   Функция может вызывать саму себя.
*   **Механика:** Каждый вызов создает **новый набор автоматических переменных** (новый кадр стека). Предыдущие значения сохраняются.
*   **Примеры:**
    *   `printd(n)`: Печатает число, рекурсивно вызывая себя для старших цифр, затем печатает младшую.
    *   `qsort(v, left, right)`: Быстрая сортировка. Выбирает опорный элемент, разделяет массив и рекурсивно сортирует подмассивы.
*   **Плюсы:** Компактный, элегантный код для рекурсивных структур (деревья).
*   **Минусы:** Расход памяти на стек, накладные расходы на вызовы.

## 4. Мастер-класс: Калькулятор с обратной польской записью (RPN)

Это **главный практический пример** главы, демонстрирующий комбинирование всех механик: I/O, массивов, внешних переменных, `switch` и функций.

### 4.1. Логика RPN
*   Операнды кладутся в стек.
*   Оператор берет операнды из стека, вычисляет результат и кладет его обратно.
*   `(1 - 2) * (4 + 5)` -> `1 2 - 4 5 + *`.
*   **Механика:** `main` использует `switch` для обработки типов токенов.

### 4.2. Стек (Внешние переменные)
```c
#define MAXVAL 100
int sp = 0;          // Внешняя переменная (индекс вершины)
double val[MAXVAL];  // Внешняя переменная (массив-стек)
```
*   `push(double f)`: Кладет значение, увеличивает `sp`.
*   `pop(void)`: Возвращает значение, уменьшает `sp`.
*   `main` не видит `sp` и `val` напрямую, он использует только `push` и `pop`.

### 4.3. Буферизация ввода: `getch` и `ungetch` (Критически важно!)
*   **Проблема:** Чтобы распарсить число, нужно прочитать символ, который **не является** частью числа (например, пробел или оператор). Этот символ уже прочитан из потока, и его нельзя потерять.
*   **Решение:** Механизм «возврата» символа во входной поток.
    ```c
    #define BUFSIZE 100
    char buf[BUFSIZE]; // Буфер для возвращенных символов
    int bufp = 0;      // Следующая свободная позиция в buf

    int getch(void) {
        return (bufp > 0) ? buf[--bufp] : getchar();
    }

    void ungetch(int c) {
        if (bufp >= BUFSIZE)
            printf("ungetch: слишком много символов\n");
        else
            buf[bufp++] = c;
    }
    ```
*   **Механика:** `getch` сначала проверяет буфер `buf`. Если там есть символы (возвращенные ранее), он берет их оттуда. Если буфер пуст — вызывает `getchar()`. `ungetch` просто кладет символ в буфер.
*   **Применение в `getop`:** `getop` читает символы, накапливает цифры в строку. Как только встречает не-цифру, он вызывает `ungetch(c)`, чтобы вернуть этот символ в поток. В следующий раз `getop` прочитает его снова.

### 4.4. Функция `getop` (Парсер)
*   Пропускает пробелы и табуляции.
*   Если символ — не цифра и не точка, возвращает его (это оператор).
*   Если цифра — накапливает строку цифр (целая и дробная часть), возвращает `NUMBER`.
*   `ungetch(c)` используется для возврата первого символа, который не является частью числа.

## 5. Препроцессор C (The C Preprocessor)

Препроцессор работает **до** компиляции. Он манипулирует текстом программы.

### 5.1. `#include`
*   `#include <stdio.h>` — поиск в системных директориях.
*   `#include "calc.h"` — поиск в текущей директории.
*   **Вложенность:** Файлы могут включать другие файлы.

### 5.2. `#define` (Макросы)
*   **Простые:** `#define MAXLINE 1000`. Текстовая замена.
*   **С аргументами:** `#define max(A, B) ((A) > (B) ? (A) : (B))`.
*   **ЛОВУШКИ МАКРОСОВ:**
    1.  **Двойное вычисление:** `max(i++, j++)` увеличит `i` и `j` дважды! (Опасно с побочными эффектами).
    2.  **Отсутствие скобок:** `#define square(x) x*x`. Вызов `square(z+1)` развернется в `z+1*z+1`, что неверно. Нужно `((x)*(x))`.
*   **Оператор `#`:** Превращает аргумент макроса в строку. `#define dprint(expr) printf(#expr " = %g\n", expr)`. `dprint(x/y)` -> `printf("x/y" " = %g\n", x/y)`.
*   **Оператор `##`:** Конкатенация (склеивание) токенов. `#define paste(front, back) front ## back`. `paste(name, 1)` -> `name1`.
*   **`#undef`:** Отменяет определение макроса.

### 5.3. Условная компиляция
*   `#if`, `#elif`, `#else`, `#endif`.
*   `defined(NAME)` — истина, если NAME определен.
*   **Защита от повторного включения (Header Guards):**
    ```c
    #ifndef HDR
    #define HDR
    /* Содержимое hdr.h */
    #endif
    ```
    Это предотвращает многократное включение одного и того же файла, что вызывает ошибки «повторного определения».
